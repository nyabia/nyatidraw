그림을 다른 곳으로

복사해서 붙여넣기

  1. NyatiDraw를 새 탭에서 열고 그림을 그립니다.
  2. 메뉴에서 PNG 복사를 누르고 복사 완료 안내를 기다립니다.
  3. 원래 SNS·메신저로 돌아가 작성창에 붙여넣습니다. PC는 Ctrl+V, 모바일은 붙여넣기를 사용합니다.

투명도를 유지한 출력 캔버스만 복사합니다. 체크무늬와 바깥쪽 스케치는 포함하지 않습니다. 복사할 수 없는 브라우저에서는 PNG 내보내기로 파일을 받아 첨부하세요.

일반 웹판은 마지막 브라우저 작업을 복원합니다. 새 그림은 직접 시작하세요. 복사는 원본 저장이 아닙니다. 중요한 그림은 작업 파일(.ntdr)로 보관하세요. 이미지 붙여넣기 지원과 권한은 브라우저 및 받는 앱에 따라 다릅니다.

Misskey 위젯에 바로가기 두기

AiScript App 위젯에 다음 링크 예제를 넣습니다. 별도 인증이나 업로드 서버는 필요하지 않습니다. 자동 첨부는 하지 않으며, 사용자가 그림을 복사하고 작성창에 붙여넣습니다.

Ui:render([
  Ui:C:mfm({ text: "[그림 그리기 ↗](https://nyabia.github.io/nyatidraw/draw/)" })
])

서버 버전과 포크별 위젯 동작은 별도 확인이 필요합니다.

웹사이트에 편집기 넣기

직접 만드는 사이트라면 iframe 또는 팝업에서 PNG를 돌려받는 JavaScript SDK를 사용할 수 있습니다. iframe은 표시할 패널과 초기값을 지정할 수 있고, 팝업은 전체 UI를 유지합니다.
