QUICK START

작업 폴더에서
시작하세요.

  1. 설치하고 그림 열기

    설치판에서 열기로 PNG 또는 .ntdr 파일을 선택합니다. 빈 그림은 새 그림에서 저장 위치를 먼저 정합니다.

  2. 그리고 저장하기

    브러시와 레이어로 수정하고 S로 저장합니다. Z는 실행 취소, Shift + Z는 다시 실행입니다.

  3. 게임 작업으로 돌아가기

    PNG 저장이 끝나면 Godot으로 돌아갑니다. 다시 편집할 때는 같은 PNG 또는 옆의 .ntdr을 열면 됩니다.

WHAT WORKS TODAY

작게 시작하는 알파판.

기본 편집부터 사용할 수 있도록 만들고 있습니다.
아직 동작하지 않는 조작은 앱에서 ‘준비 중’으로 표시합니다.

기본 편집

  • 연필 · 펜 · 브러시 · 지우개
  • 선택 · 채우기 · 그라데이션
  • 레이어 · 그룹 · 실행 취소
  • 확대 · 이동 · 화면 회전
  • 프로젝트 저장 · PNG 출력

아직 준비 중

  • 뭉개기 · 고급 브러시
  • 브러시의 실제 획 미리보기
  • 레이어 색상화 · 전경/배경 교환
  • 마우스 핸들을 이용한 자유 변형
  • 웹 편집기 · Windows 외 플랫폼

변형은 수치 입력과 뒤집기·90° 회전을 지원합니다. 레이어 불투명도는 현재 50%/100% 전환입니다. 실제 펜과 다양한 GPU에서의 장시간 사용은 추가 확인 중입니다.

새 알파판은 앱에서 확인하고 내려받습니다. ‘저장 후 업데이트’를 누르면 저장을 마친 뒤 새 버전에서 현재 그림을 다시 엽니다.
