그리기 시작할 때부터, 그림을 다른 곳에서 쓸 때까지.
NyatiDraw는 직접 쓰며 다듬고 있는 드로잉 도구입니다.

## 처음 오셨나요?

- [처음 그리기](guide/start/): 새 그림, 도구 선택, 그림 이동과 화면 이동.
- [펜과 손가락](guide/input/): 입력 모드, 팜 리젝션, 앱 필압 설정.
- [저장과 PNG 공유](guide/save/): 편집 가능한 원본과 다른 앱에 전달할 이미지.

## 다른 웹사이트에서 사용하기

- [작성창 옆에 그리기 버튼](integration/userscript/): 유저스크립트로 사이트마다 버튼 위치를 지정합니다.
- [웹 편집기 SDK](integration/embedding/): 자신이 만드는 사이트에서 iframe이나 팝업으로 PNG를 돌려받습니다.

:::caution[아직 알파입니다]
중요한 그림은 NTDR 원본을 따로 보관하세요. 브라우저 복구 데이터만을 백업으로 믿지 마세요.
데스크톱과 웹은 UI와 편집 코어를 공유하지만, 모든 플랫폼·펜 기기에서 동일하게 검증된 것은 아닙니다.
:::
