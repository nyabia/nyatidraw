## 원본과 이미지

**NTDR**은 레이어를 유지하고 다시 편집할 작업 파일입니다.
**PNG**는 다른 앱에서 사용할 합성 이미지입니다. PNG만으로 레이어를 복구할 수는 없습니다.
둘 다 출력 용도가 다르므로 중요한 작품은 NTDR 원본을 따로 보관하세요.

### 웹

메뉴의 **작업 파일 저장**으로 NTDR을 다운로드합니다.
웹은 브라우저에 복구 데이터를 남기지만, 사이트 데이터 삭제나 저장 공간 정리로 사라질 수 있습니다.
브라우저 복구 데이터는 백업을 대신하지 않습니다.

### Windows

PNG를 열면 같은 폴더에 짝 NTDR이 있는지 확인합니다.
저장 시 프로젝트와 출력 PNG를 갱신해 Godot 등의 작업 폴더에서 사용할 수 있습니다.
프로젝트 저장과 이미지 출력은 별도 작업이므로 오류가 표시되면 어느 쪽이 실패했는지 확인하세요.

## PNG 복사·붙여넣기

1. 웹 편집기 메뉴에서 **PNG 복사**를 누릅니다.
2. 복사 완료 안내가 나오면 원래 SNS·메신저 작성창으로 돌아갑니다.
3. **Ctrl+V** 또는 기기의 붙여넣기를 사용합니다.

출력 캔버스 안쪽만 복사하며 투명도를 유지합니다. 체크무늬·UI·바깥쪽 스케치는 포함하지 않습니다.
복사해도 그림을 지우거나 탭을 닫지 않습니다. 자동 업로드·자동 게시 기능은 아닙니다.

:::note[붙여넣기가 안 된다면]
HTTPS와 이미지 클립보드 지원이 필요합니다. 받는 앱도 이미지 붙여넣기를 지원해야 합니다.
안 되면 **PNG 내보내기**로 파일을 받아 첨부하세요.
:::

작성창 옆에서 바로 시작하려면 [범용 유저스크립트](../../integration/userscript/)를 사용할 수 있습니다.
