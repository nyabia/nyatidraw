## 선화 아래에 채우기

1. 선화 아래에 빈 레이어를 만들고, 그 빈 레이어를 선택합니다.
2. **채우기(F)** → **다른 레이어도 참조**를 선택합니다.
3. 색을 고르고 선 안쪽을 누릅니다. 선화는 그대로 두고 선택한 레이어에 색을 넣습니다.

러프나 자료 레이어가 보이면 그 선도 경계로 읽습니다. 불필요한 레이어를 숨기거나,
선화에 **참조 표시**를 켜고 **참조 레이어만**으로 바꾸세요.
같은 레이어에 그린 선을 기준으로 칠할 때는 **현재 레이어만**을 사용할 수 있습니다.

## 색이 새거나 가장자리가 비면

| 증상 | 조절할 항목 |
|---|---|
| 색 차이가 조금 있어 영역이 끊김 | **허용 오차**를 조금 높입니다. 너무 높으면 약한 선을 넘어갑니다. |
| 선이 덜 닫혀 밖으로 샘 | **틈 닫기**를 조금 높입니다. 0이면 끕니다. 좁은 통로도 막힐 수 있습니다. |
| 선과 색 사이에 흰 틈이 남음 | **선 밑으로 확장**을 조금 높입니다. |
| 선택한 부분만 칠해짐 | 선택 영역 안에서만 채우는 동작입니다. 전체 그림에서 작업하려면 **Esc**로 선택을 해제합니다. |
| 칠하기가 거절됨 | 대상 레이어와 상위 그룹의 **표시**를 켜고 **픽셀 잠금**을 해제합니다. |
| 칠해도 안 보이거나 일부만 바뀜 | 대상과 상위 그룹의 **불투명도**를 확인합니다. **투명도 잠금**이 켜져 있으면 이미 칠해진 부분만 바뀝니다. |

숫자를 입력하거나 슬라이더를 끌어 조절할 수 있습니다. 잘못 채웠으면 **Z**로 되돌립니다.
틈 닫기는 원본 선화를 수정하지 않으며, 모든 틈을 알아서 해결하는 기능은 아닙니다.

**추가 옵션 → 최소 1px 빈틈 보정**은 확장을 0으로 두어도 선 아래 한 픽셀을 받칩니다.
정교한 안티앨리어싱이나 부드러운 선택 경계를 만드는 기능은 아닙니다.

## 올가미로 정한 모양 전체 칠하기

올가미나 사각형으로 선택한 뒤 채우기 속성의 **선택 전체 채우기**를 누릅니다.
버킷과 달리, 안쪽 선 경계와 관계없이 선택한 모양 전체가 칠해집니다.

선 밖까지 대충 둘러싸서 자동으로 선 안쪽만 판별하는 도구는 아직 아닙니다.

## 설정 기억

채우기의 참조 범위와 허용 오차는 마법봉·스포이트와 별도로 기억합니다.
이전 파일의 설정은 보존되므로, 빈 레이어에서 전체가 칠해지면 먼저
**다른 레이어도 참조**가 선택되어 있는지 확인하세요.
