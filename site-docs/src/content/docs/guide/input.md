**메뉴 → 환경설정 → 입력**에서 모드를 고릅니다.
입력 모드와 필압 매핑은 프로젝트가 아닌 앱 설정입니다.

| 모드 | 캔버스에서의 동작 |
| --- | --- |
| 자동 | 펜을 우선합니다. 마지막 펜 활동 후 700ms가 지나면 새로운 손가락 터치를 허용합니다. |
| 펜 | 손가락으로 그리지 않습니다. 메뉴·도구 등 UI 터치는 사용할 수 있습니다. |
| 손가락 | 대기 없이 선택한 도구로 그립니다. 화면 이동 도구를 고르면 팬합니다. |

자동 모드에서 펜 접촉 중 이미 닿아 있던 손바닥이 시간이 지났다고 갑자기 획이 되지는 않습니다.
손가락 모드에서도 펜을 쓸 수 있지만 두 입력으로 동시에 획을 만들지는 않습니다.
마우스 입력은 이 모드와 별개입니다.

## 손떨림 보정

왼쪽 **도구 속성 → 손떨림 보정**에서 슬라이더를 드래그하거나 숫자를 입력합니다.
불투명도 아래에 있으며, 범위는 **0~100**, 처음 사용할 때는 **0(꺼짐)**입니다.
이전에 저장한 브러시 설정이 있으면 그 값을 복원합니다.

값을 높이면 손의 작은 흔들림을 줄이고 획을 부드럽게 연결합니다.
대신 선이 커서를 조금 늦게 따라올 수 있으므로 필요한 만큼만 올리세요.
변경한 강도는 다음 획부터 적용됩니다.

0에서는 보정 없이 입력대로 그립니다. 입력 정밀도를 낮추는 설정이 아니며,
마우스·펜의 좌표 수집과 손떨림 보정은 별개입니다.
선택과 화면 이동에는 이 브러시 보정을 적용하지 않습니다.

## 필압

환경설정의 **펜 필압**에서 직선·부드럽게·더 부드럽게를 선택할 수 있습니다.
적은 압력으로도 더 큰 출력값을 얻고 싶다면 부드러운 설정을 사용하세요.

브러시마다 크기·불투명도에 필압을 적용할지는 왼쪽 **도구 속성 → 추가 옵션**에서 지정합니다.
앱 전체 필압 매핑과 브러시별 옵션은 서로 다른 설정입니다.

:::note[기기별 차이]
필압과 팜 리젝션은 기기·드라이버·브라우저의 이벤트에 영향을 받습니다.
모든 펜과 iPad에서의 하드웨어 동작이 검증된 것은 아닙니다.
:::
