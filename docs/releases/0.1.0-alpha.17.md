# NyatiDraw 0.1.0-alpha.17

Windows x64 알파와 웹 실험판을 함께 갱신합니다.

## 주요 변경

- **그림 이동**을 G 도구 그룹의 첫 도구로 추가했습니다. 선택 영역이 없으면 현재
  래스터 레이어 전체를, 있으면 선택한 그림과 선택 영역을 함께 옮깁니다.
  페이지 밖 그림도 유지하며, 손을 떼면 한 번의 Undo로 되돌릴 수 있는 편집으로 확정합니다.
  도구 속성에서 출력 캔버스 기준 가로·세로 중앙 정렬도 가능합니다.
  손 아이콘의 **화면 이동**과 **변형**은 별도 도구입니다.
- 메뉴의 **환경설정 → 입력**에서 자동·펜·손가락을 선택할 수 있습니다.
  자동은 펜 접촉 중 터치를 막고, 마지막 펜 활동 이후 700ms가 지나면 새 손가락 입력을
  허용합니다. 이미 닿아 있던 손바닥을 뒤늦게 획으로 바꾸지는 않습니다.
  펜 모드는 캔버스 터치를 끄고, 손가락 모드는 대기 없이 선택한 도구를 사용합니다.
  펜과 손가락으로 동시에 그리지는 않습니다. UI 터치와 마우스는 막지 않습니다.
- 입력 모드와 필압 감도는 프로젝트가 아닌 앱 환경설정입니다.
  작업 명령과 환경설정을 메뉴 안에서 분리했습니다.
- 웹 메뉴에 **PNG 복사**를 추가했습니다. 투명도를 유지한 출력 캔버스를 복사하고,
  체크무늬·UI·페이지 밖 스케치는 제외합니다. 다른 SNS 작성창으로 돌아가 직접 붙여넣으세요.
  복사가 실패하면 안내 후 PNG 내보내기를 사용할 수 있으며 그림을 버리거나 창을 닫지 않습니다.
- [연동 가이드](https://nyabia.github.io/nyatidraw/draw/integration/guide.html)에
  Misskey AiScript App 위젯의 바로가기 예제를 추가했습니다.
  로그인·서버 추가·자동 게시 없이 링크 → 그림 → PNG 복사 → 직접 붙여넣기 방식입니다.
- 기존 **흰 배경** 명령은 웹에서도 사용할 수 있습니다. 별도 배경 기능을 중복 추가하지 않았습니다.

## 검증과 제한

- 공용 핵심 테스트, native/WASM Clippy, 웹/Worker 빌드를 확인했습니다.
- 격리 Edge에서 실제 PNG 클립보드 쓰기·붙여넣기와 내보내기 결과의 픽셀 일치,
  실패 안내·그림 보존, 그림 이동, 앱 설정 복원, 흰 배경 PNG를 확인했습니다.
- 페이지 밖 그림 이동과 Undo/Redo 후 별도 프로세스로 NTDR을 다시 열었고,
  브라우저에서 저장한 NTDR도 native/web artwork root가 일치했습니다.
- 터치·펜 우선 규칙은 합성 입력과 코드 검토로 확인했습니다. 실제 Windows 터치/펜,
  iPad Safari의 팜 리젝션 감각, 설치 업데이트, 실제 Misskey 서버 업로드는 미검증입니다.
- PNG 복사는 HTTPS와 이미지 클립보드 지원이 필요합니다. 받는 앱이 이미지 붙여넣기를
  지원해야 하며, 실패하면 PNG 파일 첨부를 사용하세요. 복사는 NTDR 원본 저장을 대신하지 않습니다.
