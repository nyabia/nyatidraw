# NyatiDraw 0.1.0-alpha.10

Windows x64 알파 릴리스입니다. 설치 파일은 **NyatiDraw-win-Setup.exe**입니다.
자체 건식 연필 두 가지와 도구·색상·레이어 조작을 개선했습니다.

## 주요 변경

- 연필의 세부 도구에 **2H 샤프펜슬·2B 연필** 추가. 문서 좌표에 고정된 종이 결과
  서로 다른 필압·흑연 부착 표현을 사용합니다. 외부 브러시 엔진을 가져온 구현이 아닙니다.
- 검정 연필, 5px, 불투명도 100%로 시작. 템플릿별 크기와 설정은 실행 중 따로 기억하며,
  속성 상단에는 실제 엔진을 사용하는 획 미리보기를 표시합니다.
- 스포이트 단축키 **C**, Alt 임시 스포이트. 접촉 중 확대 픽셀·후보색을 표시하고
  손을 뗄 때 색을 확정합니다. 취소·포커스 손실 뒤 오래된 결과가 색을 바꾸지 않도록 처리합니다.
- 최근색은 색을 고를 때가 아니라 실제 그리기 시작에 기록합니다. 상단과 색상 패널은
  고정색을 포함한 최대 10칸을 공유하며, 고정색은 사용자 설정으로 보존합니다.
- 색상환 안쪽 사각형 배치 수정, 불필요한 색상 코드·기본 팔레트 제거.
- 레이어 불투명도 드래그 추가. 놓을 때 한 번 적용하며 Undo 한 번으로 복원합니다.
  합성 모드·잠금·참조 설정을 목록 위로 모아 레이어 이름 공간을 확보했습니다.
- 선택 액션을 아이콘으로 정리하고, 변형 중 도구 전환·Esc 취소 경로를 보완했습니다.
- 버거 메뉴는 기존 상단 줄을 덮고, 페이지 설정은 별도 대화상자로 열립니다.
  상단 취소 버튼과 닫을 수 있는 일시 알림을 제공합니다.

## 파일 호환과 주의

- 기존 프로젝트와 이전 브러시 기록의 재생은 유지합니다. **새 연필 v3로 그린 프로젝트는
  이를 모르는 구버전 앱에서 열 수 없습니다.** 중요한 작품은 업데이트 전에 사본을 보관하세요.
- 페이지 밖 그림 보존, PNG의 출력 페이지 범위, 히스토리 128개 제한은 유지됩니다.
- 두 연필은 초기 건식 모델입니다. 기울기에 따른 옆면 표현, 습식 혼색·번짐은 아직 없습니다.
- 프로젝트 X/Y 반복, 비파괴 레이어 색상화, 메시 변형은 **미구현**입니다.
- 레이어 불투명도는 드래그 중 그림에 실시간 미리보기하지 않고 놓을 때 적용합니다.

## 확인 범위와 남은 검수

- 핵심 검사, workspace Clippy, DX 릴리즈 빌드와 저장 후 별도 프로세스 재열기를 확인했습니다.
- RTX 3080/Vulkan에서 두 연필의 검정 GPU/CPU 비교 결과는 바이트 차이 0이었습니다.
  기존 브러시 비교의 허용 오차는 늘리지 않았습니다.
- RTX 3080/Dx12 실제 릴리즈 창에서 두 연필 획·미리보기, 최근색 기록 시점,
  C 스포이트의 색 확정, 선택 아이콘, 레이어 불투명도 Undo/Redo를 확인했습니다.
  저장·프로세스 재시작 후 그림과 불투명도, 다시 출력한 PNG도 보존됐습니다.
- **사용자 실사용 검수 전 알파 배포입니다.** 확대 버블의 접촉 중 표시·추종 감각,
  Alt/취소·빠른 입력 조합, 물리 펜, 다른 DPI·모니터, 장시간 작업과 설치 업데이트는
  추가 검수가 필요합니다. 자동 검사가 이 범위를 대신하지 않습니다.
- Linux/macOS 배포와 게시자 코드 서명은 포함하지 않습니다.

상세 구현/미구현 목록과 검증 경계는 `docs/sprints/ux-feedback-checklist.md`,
자체 연필 계약은 `docs/research/pencil-brush-design.md`에 기록했습니다.
