# NyatiDraw 0.1.0-alpha.11

Windows x64 알파 릴리스입니다. 설치 파일은 **NyatiDraw-win-Setup.exe**입니다.
캔버스 크기를 프리셋과 누적 배율로 빠르게 설정할 수 있습니다.

## 주요 변경

- 상단 **페이지** 버튼의 이름을 **캔버스**로 변경했습니다.
- 자주 쓰는 **FHD 16:9 (1920×1080)**, **UXGA 4:3 (1600×1200)**,
  **64×64 정사각형**을 버튼으로 제공합니다. 다른 해상도는 **더보기**에서 고릅니다.
- **×2 / ×3 / ×5**는 현재 가로·세로에 곱하는 버튼입니다. 여러 번 누르면 누적되며,
  FHD에서 ×2를 누르면 3840×2160이 됩니다. 수치를 직접 입력하면 **커스텀**으로 표시합니다.
- **되돌리기**는 설정창 안의 최근 크기 조작만 복원합니다. 작품 Undo와 별개이며
  **적용** 전에는 문서가 바뀌지 않습니다.
- **가로·세로 교환** 버튼을 추가했습니다. 그림을 회전하거나 확대하는 기능이 아니라
  출력 영역의 폭과 높이를 바꿉니다. 그림과 출력 영역 바깥 내용은 보존합니다.
- 현재 출력 한도인 67,108,864픽셀을 넘는 배율 버튼은 비활성화하고,
  직접 입력한 크기도 적용 전에 검사합니다.

## 파일 호환과 주의

- 이번 변경으로 프로젝트 형식이나 브러시 엔진 버전은 바뀌지 않습니다.
- alpha.10의 새 연필 v3로 그린 프로젝트는 이를 모르는 구버전에서 열 수 없습니다.
  중요한 작품은 업데이트 전에 사본을 보관하세요.
- 히스토리 128개 제한과 출력 영역 밖 그림 보존은 유지됩니다.
- 프로젝트 X/Y 반복, 비파괴 레이어 색상화, 메시 변형은 여전히 미구현입니다.

## 확인 범위와 남은 검수

- Windows 릴리즈 앱에서 프리셋, 누적 배율, 직접 입력, 설정창 되돌리기,
  가로·세로 교환과 적용 전 취소를 확인했습니다.
- 임시 그림을 2160×3840으로 변경한 뒤 작품 Undo/Redo, 저장, 프로세스 종료와
  재열기를 확인했습니다. 기존 획의 content root가 유지됐고,
  재열기 후 다시 출력한 PNG의 크기와 SHA-256도 같았습니다.
- 로컬의 기존 핵심 테스트 전체·fmt·workspace Clippy와 DX 릴리즈 빌드를 통과했습니다.
  캔버스 크기/작품 history 원자성 검사도 포함합니다. 릴리즈 CI에서도
  기존 핵심 테스트 전체·fmt·Clippy·빌드·패키징을 검사합니다.
- **사용자 실사용 검수 전 알파 배포입니다.** 이번 버전의 설치·업데이트 설치,
  물리 펜, 다른 DPI·모니터, 장시간 작업은 추가 검수가 필요합니다.
  로컬 설치본은 교체하지 않았습니다. Linux/macOS 배포와 게시자 코드 서명은 포함하지 않습니다.

설정 동작의 상세 규칙은 `docs/editor-ui-target.md`에 기록했습니다.
