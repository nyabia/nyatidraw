# NyatiDraw 0.1.0-alpha.13

Windows x64 알파 릴리스입니다. 설치 파일은 **NyatiDraw-win-Setup.exe**입니다.
웹 실험판은 같은 UI와 NTDR 형식을 사용하며, 기능 지원 범위는 데스크톱과 다릅니다.

## 주요 변경

- 시작 필압이 0이었다가 짧은 이동 중 올라오면 자국 없이 끝나던 문제를 수정했습니다.
  처음 유효한 필압을 일반 브러시 간격보다 일찍 받아도 자국을 남깁니다.
- 작은 2H 연필 탭이 종이 질감과 8비트 반올림 때문에 완전히 투명해지는 문제를
  수정했습니다. 기본 크기는 그대로이며 매우 연한 부분의 질감은 조금 촘촘해질 수 있습니다.
- 웹 자동 복구 저장의 NTDR 압축·파일 생성·IndexedDB 쓰기를 별도 Web Worker로
  옮겼습니다. 연속된 저장 요청은 최신 상태로 묶으며 수동 파일 저장도 같은 경로를 사용합니다.
- 웹의 미리보기 갱신을 획 뒤로 늦췄습니다. Worker는 정적 사이트 자산으로 배포하며
  별도 서버나 공유 메모리 설정을 요구하지 않습니다.

## 호환성과 주의

- 기존 획은 기록된 이전 브러시 엔진으로 재생하므로 과거 그림의 결과를 유지합니다.
- **새 엔진의 획을 기록한 NTDR는 이전 앱에서 열 수 없습니다.** 알 수 없는 브러시
  의미론을 이전 버전이 잘못 재생하거나 덮어쓰지 못하도록 거부합니다. 함께 사용하는
  데스크톱도 업데이트하고 중요한 작품은 사본을 보관하세요.
- 웹 저장 실패는 저장 완료로 표시하지 않습니다. Worker 실패 후 수동 저장으로 현재
  그림을 구조할 수 있지만 Worker에만 있던 세션 중간 저장 기록은 복구하지 못할 수 있습니다.
- 웹 브러시 계산·미리보기·파일 열기는 메인 스레드에 남아 있습니다. 모든 입력 지연을
  해결했다거나 데스크톱과 동일한 성능·기능을 제공한다는 뜻은 아닙니다.

## 확인 범위

- 전체 workspace 핵심 테스트, 전체 타깃 Clippy, 서식 검사와 DX 웹 release 빌드 통과.
- 0→양의 필압의 0/1px 획과 4,096개 작은 연필 탭의 핵심 회귀 검사 통과.
  이전 브러시 버전 재생, 패킷 분할, 불투명도/flow 0을 함께 검사했습니다.
- Windows 11 / RTX 3080 / Vulkan의 새 연필 및 필압 시작 fixture에서 CPU/GPU
  픽셀 결과가 일치했습니다. 물리 펜과 화면 표시 지연 측정은 아닙니다.
- 웹 8회 Undo/Redo, 전체/차분 Worker 저장, 별도 프로세스 native/web 재열기 통과.
- 별도 Edge 시험 프로필에서 실제 NTDR 다운로드→파일 열기→브라우저 프로세스
  종료·재실행을 확인했고 그림 미리보기가 일치했습니다. 사용자 그림은 변경하지 않았습니다.
- 실물 펜, 대형 작품 장시간 사용, 이번 버전의 설치·업데이트 설치는 별도 검수입니다.
  로컬 설치본은 교체하지 않았습니다. Linux/macOS 네이티브 배포는 포함하지 않습니다.
