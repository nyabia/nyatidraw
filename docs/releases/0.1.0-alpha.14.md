# NyatiDraw 0.1.0-alpha.14

Windows x64 알파 릴리스입니다. 설치 파일은 **NyatiDraw-win-Setup.exe**입니다.
웹 실험판도 같은 Dioxus UI·편집 코어·`.ntdr` 형식을 사용합니다.

## 주요 변경

- 웹에서 선택·채우기·그라데이션·레이어와 그룹 편집·변형을 사용할 수 있도록
  연결했습니다. 데스크톱의 편집 로직을 공용 코어로 옮겨 양쪽에서 사용합니다.
- 변형 중 다른 도구를 선택하면 유효한 변형과 붙여넣기를 확정합니다. 변경 없는
  변형만 취소하며, 확정에 실패하면 현재 도구와 미확정 작업을 유지합니다.
- 웹 스포이트에 확대 미리보기를 연결했습니다. 색은 드래그를 놓을 때 적용하고,
  Esc로 취소합니다. 도킹 위치를 바꿔도 같은 캔버스를 유지하며 배치를 복원합니다.
- 데스크톱 **새 그림**은 저장 위치를 먼저 묻지 않고 투명 래스터 한 장을 엽니다.
  Sketchbook에 이름이 겹치지 않는 작업 파일을 자동으로 마련합니다.
- 데스크톱 버거메뉴에서 **최근 그림** 최대 20개를 선택할 수 있습니다. 파일을
  지정하지 않고 실행하면 존재하는 최근 그림을 이어 엽니다. 작품은 자동 삭제하지 않습니다.

## 호환성과 주의

- 중요한 작품은 업데이트 전에 사본을 보관하세요. 웹에서도 작업 파일은 `.ntdr`입니다.
- 웹은 한 변 4096px, 메모리 타일 1024개, 그룹을 포함한 레이어 노드 32개의
  기존 자원 제한을 유지합니다. 데스크톱과 모든 성능·기능이 같다는 뜻은 아닙니다.
- 웹 복사·잘라내기·붙여넣기는 앱 세션 내부입니다. OS 클립보드 교환과 데스크톱의
  이력 분기 탐색, 파일 연결·동일 경로 덮어쓰기는 별도입니다.
- 웹 NTDR 생성·압축·자동 복구 저장은 Worker에서, 브러시·편집·표시는 메인 WASM에서
  처리합니다. 브라우저 복구만 믿지 말고 중요한 그림은 작업 파일로 내려받으세요.
- X/Y 반복, 메시 변형, 레이어 색상화·래스터 마스크 등 후속 기능은 이번 배포에 없습니다.

## 확인 범위

- 전체 workspace 핵심 테스트·Clippy·서식, WASM Clippy, Windows·웹·Worker release 빌드 통과.
- 웹 선택·변형·레이어/그룹 편집과 도킹 후 그리기를 격리 Edge 프로필에서 확인했습니다.
  NTDR 다운로드·다시 열기와 별도 브라우저 프로세스의 자동 복구 결과를 비교했습니다.
- 공용 편집 핵심 검사에서 미확정 작업 보존, 취소, 선택 밖 픽셀 보존과 native/web
  저장·별도 프로세스 재열기를 확인했습니다.
- 격리 Windows debug/release의 WebView 메뉴에서 새 그림·최근 그림 전환·목록 갱신,
  Save·PNG export를 확인했습니다. 별도 release 프로세스의 기존 최근 그림 재개도 확인했습니다.
- 이번 새 그림 자체의 마지막 프로세스 재열기, OS 종료 버튼, 실제 펜·고주사율·대형 작품,
  설치 및 업데이트 설치는 미검증입니다. 로컬 설치본은 교체하지 않았습니다.
