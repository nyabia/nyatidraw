# NyatiDraw 0.1.0-alpha.15

Windows x64 알파 릴리스입니다. 설치 파일은 **NyatiDraw-win-Setup.exe**입니다.
웹 실험판도 함께 갱신합니다.

## 주요 변경

- 편집기 UI의 텍스트 선택을 기본 차단하고, 수정 가능한 숫자·텍스트 입력란에서만
  선택을 허용합니다. iPad Safari의 불필요한 선택 메뉴를 억제하는 WebKit 스타일도 적용했습니다.
- 웹의 마지막 도구·브러시 크기·불투명도·색상 등을 앱 설정으로 기억합니다.
  프로젝트에 설정이 있으면 파일 값이 우선이며, 없는 경우 앱의 마지막 값을 사용합니다.
- 명시적으로 저장하면 설정을 수정하지 않았더라도 프로젝트와 앱 양쪽에 현재 값을 기록합니다.
  파일을 열어 보는 것만으로 앱의 마지막 값을 바꾸지는 않습니다.
- 웹에서 2B 연필 사용 후 펜 등 다른 도구로 전환해 저장해도 마지막 연필 종류를 보존합니다.
  데스크톱 Save 및 Save As도 현재 도구 설정을 저장 작업에 포함합니다.

## 호환성과 주의

- `.ntdr`의 도구 설정 레코드 형식은 유지합니다. 웹의 내부 Worker 전달 형식만 갱신하므로
  웹 편집기는 새로고침 후 사용하세요. 중요한 그림은 먼저 작업 파일로 보관하세요.
- 웹 앱 설정은 해당 브라우저·사이트 안에 저장하며 다른 기기나 데스크톱과 동기화하지 않습니다.
  파일에 저장된 도구 설정은 `.ntdr`로 함께 이동합니다.
- 손상되었거나 인식할 수 없는 설정은 자동 덮어쓰지 않습니다.
- 전역 필압 매핑은 조사만 했으며 이번 버전에 추가하지 않았습니다.
  향후에도 프로젝트 설정이 아닌 앱 전용 설정으로 다룰 예정입니다.

## 확인 범위

- 전체 workspace 테스트·Clippy·서식과 WASM web/worker Clippy를 통과했습니다.
- 도구 설정 우선순위·양쪽 저장·손상 설정 보존과 웹 Worker/native 재열기 핵심 검사를 통과했습니다.
- 격리 Edge 프로필에서 2B/17px/63% 설정, 펜 전환, 브라우저 프로세스 재시작과
  연필 복귀, 새 그림 상속, 파일 값 우선 적용, Save 시 앱 값 갱신을 확인했습니다.
- 일반 UI 드래그의 선택 차단, 숫자 수정, 레이어 이름 편집 중 전체 선택을 확인했습니다.
- 웹 시험 그림을 저장한 `.ntdr`을 별도 native probe 프로세스로 열어 native/web
  artwork root 일치를 확인했습니다. 사용자 작품을 시험에 사용하지 않았습니다.
- 실제 iPad Safari·물리 펜 검수, 이번 desktop 창의 Save/Save As 재시험,
  설치 및 업데이트 설치는 미검증입니다. 로컬 설치본은 교체하지 않았습니다.
