# NyatiDraw 0.1.0-alpha.8

Windows x64 알파 릴리스입니다. 설치 파일은 **NyatiDraw-win-Setup.exe**입니다.

## 주요 변경

- 웹 UI와 네이티브 wgpu 캔버스의 합성 및 입력 처리 개선.
- 사이드바 폭·패널 높이 조절, 브러시 크기·불투명도 숫자 입력.
- 레이어 이름/미리보기 드래그로 순서 변경 및 그룹 이동. 이름 변경은 더블클릭.
- 새 문서는 투명 래스터 레이어 한 장으로 시작. 로고와 설치 제품명을 NyatiDraw로 통일.
- 히스토리 보관을 128개로 제한하고 타일 저장을 Zstd 무손실 압축으로 개선.
- redb 4 저장소와 기존 알파 프로젝트의 일회성 무손실 재압축·DB 재구성.

## 기존 파일과 설치 안내

- 구형 `.ntdr`을 열면 검증된 사본으로 자동 변환하고, 원본을 같은 폴더의
  `.pre-redb4-<nonce>.bak`으로 남깁니다. 백업은 자동 삭제하지 않습니다.
- 픽셀·레이어·보관된 히스토리·캔버스 밖 그림을 보존합니다. 변환에는 임시
  디스크 공간이 필요합니다. 중요한 작품은 별도로 백업해 두세요.
- 이전 앱은 변환된 프로젝트를 읽지 못할 수 있습니다. 구버전으로 돌아가려면
  백업의 **사본**을 `.ntdr`로 복원하세요. 이 알파 호환 코드는 추후 제거 예정입니다.
- 현재 설치 경로는 `%LOCALAPPDATA%\NyatiDraw\current\nyatidraw.exe`입니다.
  과거 별도 제품 `NyatiDraw.Alpha`는 자동 제거·승계하지 않습니다.

## 확인 범위와 남은 제한

- 로컬 설치본 갱신, 핵심 저장/복구·히스토리 검사 및 브라우저 포인터 드래그 검사를 수행했습니다.
  CI에서도 테스트·fmt·Clippy·DX 릴리즈 빌드·패키징을 검사합니다.
- 실물 펜, 다양한 DPI/다중 모니터 및 장시간 편집은 추가 수동 검증이 필요합니다.
  Linux/macOS용 배포는 포함하지 않습니다.
- 프로젝트는 PNG보다 큽니다. 128개는 히스토리 **개수** 제한이며 파일 크기 제한이 아닙니다.
  편집에 따라 스트로크 기록과 DB 여유 공간이 늘어납니다. 종료 때 전체 공간 정리를 강제하지 않습니다.
- 설치 파일은 게시자 코드 서명 전이므로 Windows 보안 경고가 표시될 수 있습니다.
