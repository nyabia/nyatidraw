# NyatiDraw 0.1.0-alpha.19

큰 그림을 축소했을 때 가는 선과 질감이 너저분하게 보이던 표시 문제를 수정합니다.
Windows와 웹이 같은 캔버스 렌더러 개선을 사용합니다.

- 축소 시 원본 픽셀 하나를 골라 표시하던 방식 대신 면적 평균 mip와 배율별 보간을 사용합니다.
- 페이지 밖 그림도 같은 방식으로 줄여 표시하고, 타일 사이에 이음새가 생기지 않도록 합성합니다.
- 1:1·확대에서 픽셀을 보는 동작은 유지합니다.
- 화면 밖을 수정한 뒤 축소·이동해도 최신 그림으로 표시합니다. 투명 경계와 홀수 크기 페이지를 포함합니다.
- 원본 픽셀·Undo·NTDR 포맷·PNG 출력은 변경하지 않습니다. 기존 프로젝트를 변환할 필요가 없습니다.

실제 GPU의 합성 패턴 검사에서 24개 축소 조건, 원본 보존, 확대 픽셀 정확성, 비가시 변경,
반투명 경계와 홀수 페이지 가장자리를 확인했습니다. 브라우저·빌드·공개 자산 검증 결과는
[축소 표시 검증](https://github.com/nyabia/nyatidraw/blob/main/docs/measurements/viewport-minification.md)과
[릴리즈 기록](https://github.com/nyabia/nyatidraw/blob/main/docs/releasing.md)에 구분해 기록합니다.

이번 수정은 주 캔버스 표시 대상입니다. 내비게이터·레이어 썸네일이나 선택 변형으로 실제
픽셀을 줄이는 알고리즘은 바꾸지 않았습니다. 물리 펜·iPad Safari·설치 업데이트·입력 지연은
이번 검사만으로 확인했다고 주장하지 않습니다. 중요한 작업은 별도 NTDR 사본을 보관하세요.
