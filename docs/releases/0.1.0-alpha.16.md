# NyatiDraw 0.1.0-alpha.16

Windows x64 알파 릴리스입니다. 설치 파일은 **NyatiDraw-win-Setup.exe**이며 웹 실험판도 갱신합니다.

## 주요 변경

- 파일과 앱에 저장된 설정이 모두 없을 때 검은색 펜, 10px, 불투명도 100%로 시작합니다.
  기존 파일과 앱의 마지막 도구 설정은 계속 우선합니다.
- 새 기본 브러시의 크기·불투명도 필압 최소값을 0으로 설정합니다.
- 앱 전용 필압 매핑에 선형·부드럽게·더 부드럽게를 추가합니다. 기본은 부드럽게입니다.
  실제 펜 입력에만 적용하며 마우스는 바꾸지 않습니다. 획 시작 때 곡선을 고정하고,
  이미 저장한 획에는 다시 적용하지 않습니다. 자유 곡선 편집기는 아닙니다.
- 레이어 삭제 아이콘을 Lucide 휴지통으로 교체하고 라이선스 고지를 포함합니다.
- 웹 편집기를 iframe 또는 팝업으로 여는 JavaScript SDK와 예제를 제공합니다.
  iframe은 표시할 패널과 초기 캔버스·도구·크기·색을 지정할 수 있고, 팝업은 전체 UI입니다.
- 사용자가 완료를 누르면 PNG를 호출 페이지에 전달합니다. 호스트 수락 뒤 닫히며,
  수신 실패·시간 초과에는 그림을 유지하고 재시도 또는 수동 다운로드할 수 있습니다.
  연동 세션은 기존 브라우저 작업과 설정을 읽거나 덮어쓰지 않습니다.

## 사용법과 제한

- [웹 연동 예제](https://nyabia.github.io/nyatidraw/draw/integration/demo.html)
- [SDK 안내](https://github.com/nyabia/nyatidraw/blob/v0.1.0-alpha.16/docs/web-embedding.md)
- 연동 v1은 새 빈 그림에서 시작합니다. 초기 PNG를 넘겨 편집하는 API는 아직 없습니다.
- HTTPS와 WebGPU가 필요합니다. 서버 게시 기능은 포함하지 않으며 PNG를 받은 호스트가
  저장·첨부를 담당합니다. 임시 연동 작업은 창/호스트를 강제로 닫으면 잃을 수 있습니다.
- 작은 iframe에는 필요한 패널만 표시하세요. 전체 UI는 1280×900 정도를 권장합니다.

## 검증 범위

- 핵심 테스트, 서식, native/WASM Clippy, 웹·Worker 빌드를 확인했습니다.
- 격리된 Edge에서 다른 origin의 iframe·팝업, 실제 PNG 반환, 거절/시간 초과/재시도,
  취소 확인, 기존 작업과 복수 임베드의 저장 격리를 확인했습니다.
- 브라우저에서 내려받은 NTDR은 별도 프로세스로 재열어 native/web artwork root가 일치했습니다.
- 실제 펜 감각, iPad Safari, 설치·업데이트 설치, 외부 SNS 업로드는 이번 검증에 포함하지 않습니다.
  합성 입력 검사를 하드웨어 검수로 해석하지 마세요.
