# NyatiDraw 0.1.0-alpha.23

입력 좌표 수집과 선택적인 손떨림 보정을 분리한 알파 버전입니다.

## 변경 내용

- Windows 상대 마우스에 raw 이동량과 소수 좌표를 사용하는 경로를 추가했습니다.
  시스템 속도·가속 설정을 참고하되 OS 커서와의 누적 어긋남을 제한합니다.
  지원되지 않는 장치나 유효한 raw 입력이 없는 획은 기존 입력 경로를 유지합니다.
- 웹은 지원 브라우저에서 고빈도 `pointerrawupdate`를 사용하고, 그렇지 않으면
  `pointermove`로 그립니다. 같은 움직임을 중복해서 그리거나 정지 상태의 필압 변화를
  버리지 않도록 입력원을 획마다 고정합니다.
- 왼쪽 **도구 속성 → 불투명도 아래 → 손떨림 보정**에서 강도를 조절합니다.
  슬라이더 드래그와 숫자 입력을 지원하고, 기본값은 **0(꺼짐)**입니다.
  기존에 저장한 강도는 복원하며 변경은 다음 획부터 적용됩니다.
- 강도를 올리면 공통 Rust 경로에서 위치 안정화와 곡선 연결을 적용합니다.
  축소 배율을 고려하고, 짧은 획·필압·끝점 및 종료 시 보류된 꼬리를 보존합니다.
  Cancel과 입력 한도 초과에서는 부분 획을 남기지 않습니다.
- 평가된 획을 그대로 저장하므로 재열 때 보정이 반복 적용되지 않습니다.
  기존 프로젝트 형식과 저장된 브러시 엔진은 변경하지 않습니다.

## 제한과 검증

Windows 가속 곡선을 정확히 복제하거나 손실된 센서 좌표를 복원하는 기능은 아닙니다.
일부 입력에서는 소수 정밀도 개선이 제한될 수 있으며, 이미 저장된 픽셀을 수정하지 않습니다.
손떨림 보정을 높이면 선이 늦게 따라올 수 있습니다.

전체 workspace 테스트와 Clippy, Windows·웹 release 빌드를 통과했습니다.
실제 Windows 창과 Edge에서 그리기·강도 조절·저장·프로세스 재시작·재열기를 확인했고,
재출력 PNG의 픽셀은 저장 전과 정확히 같았습니다.

핵심 불변식 검사와 실행 검증은 [입력 검증 기록](../measurements/input-precision.md)에,
배포 확인은 [릴리즈 기록](../releasing.md)에 기록합니다.
실제 마우스/펜의 장치별 품질, iPad Safari/Apple Pencil, 고주사율 지연과 설치 업데이트는
별도 검증 범위입니다. 자동화 입력을 물리 장치 검증으로 간주하지 않습니다.
