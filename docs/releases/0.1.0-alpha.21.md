# NyatiDraw 0.1.0-alpha.21

웹의 그림 이동·터치 조작과 연필의 약한 필압 처리를 개선한 알파 버전입니다.
Windows와 웹은 같은 문서·브러시 코어와 `.ntdr` 형식을 사용합니다.

## 변경 내용

- 웹의 그림 이동 도구가 드래그 중 실제 그림을 미리 보여줍니다. 손을 떼면 한 번
  확정하고, Esc나 도구 전환으로 취소하면 원본으로 돌아갑니다.
- 레이어 행에서 손가락·펜을 쓰면 선택과 목록 스크롤이 동작합니다. 순서 변경은
  오른쪽 점 핸들을 끌어 시작합니다. 마우스의 기존 행 드래그는 유지합니다.
- 애니메이션 타임라인을 닫고 상단 버튼으로 다시 열 수 있습니다. 프레임과 선택
  상태는 유지하며, 재생 중 닫아도 재생은 계속됩니다.
- 브러시 자국 간격을 필압에 따라 작아진 실제 펜촉 크기에 맞춰 조절합니다.
  연필에서는 약한 필압이 여러 단계에서 중복으로 약해지던 처리를 개선했습니다.
- 화면 이동·그림 이동·변형 등 아이콘의 잘못된 도형을 수정하고 모양을 구별했습니다.
  레이어 추가는 `+`, Solo는 `S`로 표시합니다.

## 호환성과 제한

- 기존 획의 재생 방식은 보존합니다. **새 브러시로 저장한 프로젝트는 alpha.21 이상이
  필요할 수 있습니다.** 구버전은 이해하지 못하는 획을 조용히 생략하지 않고 거부합니다.
- Apple Pencil 몸통 더블탭·쥐기로 지우개를 전환하는 기능은 웹에서 지원 경로를
  확인하지 못해 추가하지 않았습니다. 화면의 지우개 버튼과 E 단축키를 사용합니다.
- alpha.20에서 기록한 Windows 마스크 표시 문제는 해결됐다고 간주하지 않습니다.
  저장 타일·PNG 보존과 별개인 최종 화면 합성/캡처 경로의 미확정 문제입니다.
- iPad Safari·물리 Apple Pencil의 감각, 설치 업데이트와 최종 화면 지연은 미검증입니다.

## 검증

워크스페이스 핵심 테스트, Windows·WASM Clippy, 웹/복구 Worker 릴리즈 빌드를
통과했습니다. 실제 Chromium에서 이동 미리보기·취소·Undo, 터치 스크롤과 핸들
재정렬, 타임라인 닫기·재열기를 확인했습니다. 합성 펜 입력의 약한 필압 획도 PNG에
남았고, 브라우저 프로세스 재시작 후 복구 픽셀이 일치했습니다. 저장한 웹 NTDR을
별도 네이티브 프로세스에서 열어 출력한 그림도 비트 깊이를 맞추면 일치했습니다.

GPU 약한 필압 비교 160건은 최대 채널 차이 3이었습니다. 선택 영역 검사의 일부
CPU/GPU 차이는 고정 기능 UNORM 블렌딩 대조에서도 재현되어 별도로 기록했습니다.
이는 물리 펜이나 모든 GPU에서 같은 감각·픽셀을 보장한다는 뜻은 아닙니다.
