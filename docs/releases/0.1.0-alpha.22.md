# NyatiDraw 0.1.0-alpha.22

그림을 수정한 뒤 다시 그리기로 돌아오는 동선을 다듬은 알파 버전입니다.
Windows와 웹의 공용 UI에서 선택·변형·레이어의 현재 대상과 종료 조작을 더 분명하게
표시하고, 웹 자동 복구 저장의 반복 알림을 줄입니다.

## 변경 내용

- 펜으로 도구를 바꾼 뒤에도 선택 상태와 변형·복사·선택 해제에 접근할 수 있습니다.
  선택 없이 전체 레이어를 변형하는 경로도 제공합니다.
- 변형 수치가 잘못됐거나 미리보기가 아직 확인되지 않았으면 확정을 막고 입력한
  초안을 유지합니다. 적용·취소를 명시하고, 검증된 미리보기는 편집기 초점의 Enter로
  확정합니다. 숫자 입력의 Ctrl+A는 그림 전체 선택과 구분합니다.
- 레이어 이름을 눌러도 같은 레이어의 마스크 편집 대상을 유지합니다. 이미지 썸네일을
  누르면 이미지 편집으로 돌아갑니다. 레이어 옵션 메뉴는 대상 이름을 보여주고,
  오른쪽 클릭·옵션 버튼·Shift+F10으로 열 수 있습니다. 삭제는 별도로 확인합니다.
- 작은 아이콘과 조절기에 공용 마우스 hover·키보드 focus 도움말을 제공합니다.
  기존 G/B/E/F/C 단축키와 무채색 작업공간은 유지합니다.
- 웹의 자동 복구 저장은 작은 점과 체크 표시로 알립니다. 매획 긴 성공 알림을
  반복하지 않으며, 실패 경고와 사용자가 요청한 파일·PNG 다운로드 확인은 유지합니다.
  자동 복구는 브라우저 안의 보관이며 별도 작업 파일 다운로드를 대신하지 않습니다.
- 임베드에서 새 그림으로 바꿀 때 표시되던 잘못된 자동 복구 저장 실패 알림을 없앴습니다.
- Windows의 그림 이동 도구에 드래그 중 실제 그림 미리보기를 추가합니다.
  미리보기는 원본·히스토리와 분리하고, 취소하면 원본으로 돌아갑니다.
- 타임라인을 닫을 때 재생 정지를 확인하고 닫습니다. 다시 열면 선택 프레임은
  유지됩니다. alpha.21의 숨긴 채 계속 재생하는 동작에서 변경됩니다.
- 캔버스 크기 변경은 실제 결과를 확인한 뒤 창을 닫으며, 실패하면 입력값과 오류를
  남깁니다. 좁은 툴바에서도 주요 조작을 아이콘과 접근성 이름으로 구분합니다.
- 내비게이터가 정사각형·세로 그림에서도 하단 1:1·화면 맞춤 버튼을 덮지 않도록
  미리보기를 남은 공간에 맞춥니다. 클릭과 드래그도 실제 표시 크기를 기준으로 동작합니다.

## 호환성과 제한

- 이번 UX 묶음을 이유로 기존 브러시 재생·프로젝트 호환성 약속을 변경하지 않습니다.
  alpha.21에서 도입한 브러시로 저장한 프로젝트는 alpha.21 이상이 필요할 수 있습니다.
- Windows 마스크의 최종 화면 표시 문제는 해결됐다고 선언하지 않습니다.
  저장된 픽셀·PNG 보존 검사와 최종 화면 합성/캡처 문제는 별개입니다.
- 1024×768의 앱 셸 최소 폭 문제와 태블릿 팔레트 전체 재배치는 남아 있습니다.
  이 수정은 iPad 전용 작업공간 재설계가 아닙니다.
- 실제 iPad Safari·Apple Pencil, Windows 물리 펜, 고주사율 표시 지연 및 설치 업데이트는
  별도 검증이 필요합니다. 브라우저 자동화·합성 입력을 실기기 증거로 간주하지 않습니다.

## 검증

Windows Edge의 1440×1000 브라우저에서 레이어 옵션 버튼·Shift+F10, 삭제 확인 취소와
초점 복귀, 마스크 추가·제거 취소를 확인했습니다. 도움말은 화면 안에 표시되며 기존
접근성 이름을 유지합니다. 자동 복구 완료는 작은 체크로 표시되고 반복 live 알림이나
성공 alert를 발생시키지 않았습니다.

웹의 그림 이동은 드래그 중 실제 픽셀을 보여주며, 버튼을 놓은 뒤의 표시도 같았습니다.
Undo·취소는 원래 위치로 복원됐습니다. 새 브라우저 프로세스의 자동 복구와 명시적으로
저장한 NTDR 재열기 모두 **종료 직전 출력 PNG와 RGBA가 정확히 일치**했습니다.
최초 가져오기 PNG와의 색 변환 차이는 별개이므로 가져오기 원본과의 무손실 일치를
주장하지 않습니다. 앞선 로컬 UX 묶음의 선택·변형·키보드 검증은 연결 문서에 기록합니다.

전체 workspace 핵심 테스트 280개, 전체 Clippy와 WebAssembly Clippy, 포맷 검사,
Windows 및 웹 release 빌드가 통과했습니다. 1194×834 터치 에뮬레이션에서 레이어
옵션의 대상 고정과 정사각형·세로 그림의 내비게이터 버튼 접근도 확인했습니다.
추가 이동/Undo 검사는 가져온 뒤 앱이 출력한 PNG를 기준으로 정확한 RGBA 보존을 확인했습니다.
공개 iframe 데모의 그림 교체와 호스트 PNG 반환도 오류 알림 없이 완료했습니다.

Windows release 시험 창은 실행했지만 수동 조작 검사가 중단되어 네이티브 드래그의
최종 표시 검증은 완료하지 않았습니다. 설치 업데이트와 실기기 검증도 포함하지 않습니다.
릴리즈 CI·자산·공개 웹 확인 결과는 [배포 기록](../releasing.md)에 별도로 기록합니다.
