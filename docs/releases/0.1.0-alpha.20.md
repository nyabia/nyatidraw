# NyatiDraw 0.1.0-alpha.20

일러스트 수정·마무리와 게임용 래스터 애니메이션 작업을 확장한 알파 버전입니다.
Windows와 웹은 같은 문서·편집 코어와 `.ntdr` 형식을 사용합니다.

## 먼저 확인해 주세요

- **Windows 마스크 표시는 알려진 문제가 남아 있습니다.** 메뉴 조작 뒤 창 캡처에서
  마스크로 숨긴 부분이 다시 보이는 현상을 확인했습니다. 저장된 타일·PNG와 GPU 출력
  표본은 정상이지만 최종 합성/캡처 경로의 원인은 확정하지 못했습니다. Windows에서
  마스크를 쓰는 중요한 작업은 PNG 결과를 확인하고 원본 사본을 보관하세요.
- 새 애니메이션·마스크·부드러운 선택 기록을 사용하는 프로젝트는 구버전에서 열리지
  않을 수 있습니다. 구버전이 기능을 조용히 누락한 그림을 열지 않도록 보호합니다.
  새 기능을 쓰기 전 `.ntdr` 사본을 남기세요.
- 물리 펜, iPad Safari, 설치 업데이트와 최종 화면 지연은 이번 자동 검사로 검증한
  것으로 간주하지 않습니다. Windows 실행과 브라우저 조작 증거는 아래 문서에 구분했습니다.

## 그림 편집

- Screen·Add·Overlay 합성 모드를 추가했습니다.
- 선택한 그룹의 하위 래스터를 함께 이동·회전·크기 조절할 수 있습니다.
- 레이어 원본을 지우지 않는 래스터 마스크와 실제 흑백 미리보기를 추가했습니다.
  마스크 그리기·사용 중지·삭제·선택 영역 채우기를 Undo/Redo와 함께 처리합니다.
- 부드러운 선택과 feather를 브러시·채우기·변형·색 보정·저장된 획 재생에 연결했습니다.
- 참조 이미지에서 색을 채취하고, 원본 크기를 바꾸지 않은 축소 PNG를 출력할 수 있습니다.
- 마스크 선택 후 단축키가 끊기던 Windows 포커스 오류와 Undo/Redo 뒤 편집 대상이
  이미지로 바뀌던 문제를 수정했습니다. 분기 이력의 일반 Redo는 방금 취소한 작업으로 돌아갑니다.

## 애니메이션과 게임 출력

- 프레임 추가·복제·삭제·순서 변경, 프레임별 시간, 재생과 어니언 스킨을 추가했습니다.
- 프레임별 레이어와 그림을 같은 `.ntdr`에 저장합니다.
- 실제 프레임 미리보기를 표시하고 화면 주변 프레임부터 제한된 수만 생성합니다.
- 스프라이트 시트 PNG와 프레임 위치·지속시간 JSON을 내보낼 수 있습니다.
- 기본 범위는 단일 트랙의 래스터 애니메이션입니다. 공유 배경 트랙·GIF/APNG·뼈대
  애니메이션·고급 atlas packing은 포함하지 않습니다.

## 검증 범위

코어 테스트, Windows·WASM Clippy, Windows·웹 빌드와 scratch 작품의 저장→프로세스
종료→재열기 검사를 수행했습니다. 마스크 채우기 전후의 PNG 픽셀 일치, 분기 Undo/Redo,
30프레임 스크롤, 같은 프레임 ID를 가진 문서 교체와 단축키/숫자 입력도 확인했습니다.
희소 CPU 합성은 전후 픽셀 일치와 측정을 바탕으로 개선했습니다.

이는 모든 일러스트 작업이나 Windows 표시 안정성이 검증됐다는 뜻은 아닙니다.
웹 프레임 미리보기는 지연된 메인 스레드 작업이며 대형 작품의 지연 상한을 보장하지 않습니다.
