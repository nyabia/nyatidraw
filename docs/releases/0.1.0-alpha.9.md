# NyatiDraw 0.1.0-alpha.9

Windows x64 알파 릴리스입니다. 설치 파일은 **NyatiDraw-win-Setup.exe**입니다.
일러스트 작업의 기본 도구와 브러시 조작을 확장했습니다.

## 주요 변경

- 브러시 크기/불투명도 독립 필압, 최소값, 경도와 기본 선 보정.
- 도구 속성과 크기 빠른 선택 패널 분리. 오른쪽 정렬 숫자 입력과 접힌 `추가 옵션`.
- 크기 빠른 선택 3열×4행, 최근 크기 4개는 실제 획 시작 시 기록하며 Undo/Redo와 독립.
- 페이지 밖 사각형/올가미 선택, 선택 추가·빼기, 복사·잘라내기·붙여넣기와 자유 변형.
- 참조 레이어 기반 채우기, 형태학적 틈 닫기, 채우기 확장과 선택 확장·축소.
- 투명도 잠금, 하위 레이어 클리핑, Normal/Multiply 합성으로 재칠·명암 작업 지원.
- 보기 반전·회전 복귀와 임시 스포이트 등 기본 작업 흐름 개선.

## 파일 호환과 주의

- 기존 프로젝트는 읽을 수 있지만 새 브러시·레이어 기능으로 저장하면 구버전 앱에서
  열지 못할 수 있습니다. 중요한 작품은 업데이트 전에 별도 사본을 보관하세요.
- 프로젝트에는 페이지 밖 그림과 편집 정보가 남고 PNG에는 출력 페이지 안쪽만 포함됩니다.
- 히스토리 128개 제한은 유지됩니다. 프로젝트 크기 상한을 의미하지 않습니다.
- 투명도 잠금 중 지우기·잘라내기·변형 등 지원하지 않는 편집은 명시적으로 거절합니다.

## 확인 범위

- 로컬 핵심 테스트, Clippy, DX release 빌드와 GPU/CPU 비교 및 저장 후 별도 프로세스
  재열기 검증을 수행했습니다. 상세 범위는 `docs/sprints/essentials-goal.md`를 참고하세요.
- 최근 크기/Undo 분리는 release GPU actor 검증에 포함했습니다.
- **이번 UI 변경은 사용자 실사용 확인 전 배포입니다.** 실제 설치본의 화면 배치,
  물리 펜, 다양한 DPI/모니터, 장시간 그림 작업과 업데이트 설치는 추가 확인이 필요합니다.
  자동 검사 통과가 이 수동 검증을 대신하지 않습니다.
- 저장한 패널 높이는 보존합니다. 작은 높이를 저장했다면 패널 경계를 내려 늘려주세요.
- Linux/macOS 배포 및 게시자 코드 서명은 포함하지 않습니다.
