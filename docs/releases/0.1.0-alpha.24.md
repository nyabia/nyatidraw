# NyatiDraw 0.1.0-alpha.24

Windows와 브라우저 편집 화면이 같은 GPUI Kit 기반 UI를 사용합니다. 기존 NTDR 프로젝트와 사용자 도킹 배치를 계속 열 수 있습니다.

## 변경 내용

- 패널 경계는 놓은 위치를 저장하고 키보드 방향키로도 조절할 수 있습니다. 패널을 옮기는 동안 작품과 드롭 표시가 함께 보이며, 좁은 창에서는 속성과 색·레이어 패널을 접거나 다시 열 수 있습니다.
- 레이어 행에서 여는 색 보정은 해당 레이어에 적용됩니다. 미리보기를 보며 슬라이더와 수치로 조절할 수 있습니다. 색상환 조작 직후에도 도구 단축키를 사용할 수 있습니다.
- 선택 영역 위에서 그릴 때 선택 상태와 해제 동작이 캔버스 위에 표시됩니다. 변형 작업도 같은 위치에서 적용하거나 취소할 수 있습니다.
- 채우기 속성에서 실제 대상과 작업을 막는 조건을 확인하고 이미지와 마스크 사이를 바꿀 수 있습니다. PNG 크기 지정은 가로와 세로 어느 쪽으로도 입력할 수 있습니다.
- Windows에서 문서 이름, 저장 상태, PNG 갱신 결과를 구분해 표시합니다. 웹에서는 브라우저 자동 복구 상태를 표시합니다.
- Windows에서 마우스가 있는 모니터에 창을 열 때 앱이 종료되던 문제를 수정했습니다. 캔버스 크기 창은 변경이 반영되면 닫히며, 요청이 거부되면 입력값과 오류를 확인할 수 있습니다.
- 타임라인에서 방향키와 Home/End로 프레임을 살펴볼 수 있습니다. 참조 이미지는 패널 높이에 맞춰 표시되고, 색을 채취하기 전에 색 견본을 볼 수 있습니다.

## 지원 범위

Windows 설치판과 브라우저 실험판을 제공합니다. 브라우저 편집기는 WebGPU, IndexedDB, Web Locks를 지원하는 환경에서 사용할 수 있습니다. GPUI 웹 편집 화면은 캔버스에 렌더링합니다. 바깥의 파일 대화상자와 상태 표시는 HTML로 제공하며, 캔버스 안의 도구에는 기존 DOM 편집 화면과 같은 스크린 리더 지원이 아직 없습니다.

물리 펜, iPad Safari와 Apple Pencil, 고주사율 화면의 지연은 별도 검증 영역입니다.
