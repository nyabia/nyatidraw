# NyatiDraw 0.1.0-alpha.18

Windows x64 알파와 웹 실험판을 함께 갱신합니다.

## 파일 없이 시작하고 공유하기

- 상단의 **새 그림**으로 파일 이름·저장 위치를 정하지 않고 낙서를 시작합니다.
  앱과 브라우저의 자동 복구는 유지하고, NTDR 파일 보관은 필요할 때 선택합니다.
- **PNG 복사**를 웹과 Windows 상단·메뉴에서 사용할 수 있습니다.
  현재 출력 캔버스의 합성 그림을 투명도와 함께 복사합니다. 선택 영역 복사와는 별개이며
  UI·체크무늬·캔버스 밖 스케치는 포함하지 않습니다. 파일 저장은 필요 없습니다.
- Windows의 관리되는 임시 그림은 PNG 자동 출력 없이 복구 저장합니다.
  사용자가 열거나 저장 위치를 정한 프로젝트의 NTDR·PNG 함께 저장은 유지합니다.
- 미확정 변형·색 보정이 있으면 완료하거나 취소한 뒤 복사하도록 안내합니다.
  웹의 이미지 클립보드는 HTTPS와 브라우저 지원이 필요합니다.

## 그리기·수정 흐름 보완

- 이름 있는 사용자 브러시 프리셋, 선화 참조 채우기 옵션과 경계 보존을 보완했습니다.
- 현재 래스터의 색상·채도·명도·밝기/대비를 원본 고정 미리보기로 조정하고,
  취소하거나 한 번의 Undo로 확정할 수 있습니다.
- 러프 레이어를 두 색으로 표시하는 비파괴 색상화 효과를 추가했습니다.
  원래 픽셀을 재칠하지 않습니다.
- PNG를 현재 그림의 새 레이어로 가져와 배치하고 확정·취소할 수 있습니다.
- 하위 레이어·그룹을 유지하는 그룹 복제, 전경→배경 그라데이션,
  캔버스 밖 마법봉 선택과 추가·빼기를 보완했습니다.
- 숫자 또는 Shift+Space 드래그로 화면 각도를 조절합니다. 픽셀은 바뀌지 않습니다.
- 내비게이터의 참조 탭에 PNG 자료를 놓고 확대·이동할 수 있습니다.
  참조 자료는 현재 세션 전용이며 프로젝트·PNG에 저장하지 않습니다.
- Windows 클립보드의 일부 DIB/DIBV5 이미지 읽기를 추가했습니다.
  모든 비트 깊이·압축 변형을 지원하는 것은 아닙니다.

## 검증 범위와 주의

핵심 그림·입력·저장 검사, Windows/WASM 정적 검사와 릴리즈 빌드,
격리 브라우저의 편집·저장·별도 프로세스 재열기를 배포 기준으로 사용합니다.
구체적인 결과는 [핵심 워크플로우 검증](https://github.com/nyabia/nyatidraw/blob/v0.1.0-alpha.18/docs/core-workflow-completion.md)과
[무파일 낙서 검증](https://github.com/nyabia/nyatidraw/blob/v0.1.0-alpha.18/docs/measurements/unsaved-drawing.md)을 참조하세요.

- 실제 펜 감각·iPad Safari·고주사율 화면·깨끗한 Windows 설치/업데이트는 별도 검수 대상입니다.
- 새 레이어 색상화 데이터는 이전 버전에서 열기를 거부할 수 있습니다.
  중요한 작업은 원본을 별도로 보관하고 같은 최신 버전의 웹/Windows를 사용하세요.
- 자동 복구는 백업이 아닙니다. 레이어를 다시 편집할 그림은 NTDR로 저장하세요.
- 다중 레이어 동시 변형·레이어 마스크·병합·부드러운 선택 경계는 아직 없습니다.
  이번 알파를 모든 일러스트 작업의 완성판으로 표시하지 않습니다.
