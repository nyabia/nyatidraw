# NyatiDraw 0.1.0-alpha.12

Windows x64 알파 릴리스입니다. 설치 파일은 **NyatiDraw-win-Setup.exe**입니다.
실제 그림 연습에서 발견된 입력·오류 복구·설정 복원과 저장 용량 문제를 보수했습니다.

## 주요 변경

- 필압이나 불투명도가 0인 빈 획 때문에 전체 편집이 멈추던 문제를 수정했습니다.
  빈 획은 그림과 Undo를 만들지 않고 다음 정상 획을 계속 받습니다.
- 오류 안내는 캔버스에 한 번만 표시합니다. 오류 후에도 종료 확인창의
  **프로젝트 다시 열기 / 오류를 확인하고 종료**를 조작할 수 있도록 입력 경로를 유지합니다.
- 저배율에서 많은 바깥 그림을 볼 때 GPU 타일 저장 한도 때문에 멈추던 합성을
  작은 묶음으로 처리합니다. 보이는 타일을 생략하지 않으며 진행 중인 획도 보존합니다.
- 펜으로 색상환을 조작하는 경로와 드래그 캡처를 보수했습니다. 저장 완료 알림이
  겹쳤다는 이유로 색 선택이 취소되지 않습니다. 캔버스 접촉은 수치 입력란의 포커스를 해제합니다.
- 펜의 중간/세 번째 버튼 신호는 누르는 동안 그랩, 오른쪽/배럴 버튼 신호는 임시
  스포이드로 사용합니다. 해제하면 원래 도구를 유지하며 원치 않는 꼬리 획을 막습니다.
- **캔버스** 창에서 바깥 배경을 조금 어두운 체크 또는 지정한 단색으로 바꿀 수 있습니다.
  이 배경은 그림·PNG·스포이드·Undo에 들어가지 않으며 다시 실행해도 유지됩니다.
- 프로젝트별 도구, 연필 종류, 도구별 크기·불투명도·필압·경도·보정 및 앞뒤 색을 복원합니다.
  저장된 설정이 없는 새 작업은 마지막 사용 설정, 그것도 없으면 연필·검정으로 시작합니다.
- 저장 버튼을 누르지 않고 닫아도 받아들인 마지막 획까지 프로젝트와 PNG에 반영합니다.
  같은 실행에서 이미 최신 PNG를 출력했다면 불필요한 재인코딩을 생략합니다.
- 반복 저장되던 타일 목록을 무손실 압축하고 기존 알파 파일을 한 번만 안전하게
  재구성합니다. 픽셀 정밀도와 보관 중인 128단계 히스토리는 줄이지 않습니다.
  실사용 그림 사본은 **39.46 MB → 8.71 MB(약 78% 감소)**였고, 모든 기록과
  129개 히스토리 상태의 타일·레이어·캔버스가 유지됐습니다. 원본은 변경하지 않았습니다.

## 파일 호환과 주의

- 이번 버전은 저장 형식의 새 압축 표시를 사용합니다. **변환된 NTDR는 이전 앱에서 열 수 없습니다.**
  기존 파일을 변환할 때 원본 백업을 옆에 보존하며, 검증 실패 시 원본을 교체하지 않습니다.
  중요한 작품은 업데이트 전에도 사본을 보관하세요.
- 변환은 기존 파일의 첫 열기에서 한 번 수행합니다. 이후 매번 저장·종료할 때 전체
  재압축을 하는 방식은 아닙니다. 용량 감소율은 파일별로 다릅니다.
- PNG 출력 실패는 NTDR 저장과 분리됩니다. 종료 경고에서 저장된 프로젝트를 다시 열거나
  오류를 확인하고 종료할 수 있습니다.
- 프로젝트 X/Y 반복, 비파괴 레이어 색상화, 메시 변형은 이 안정성 보수에 포함하지 않습니다.

## 확인 범위

- 전체 workspace 핵심 검사와 별도 프로세스 저장·재열기 검사를 수행했습니다.
  빈 획 후 계속 그리기, 종료 PNG 일치, PNG 실패 시 프로젝트 보존,
  도구 설정/다른 이름으로 저장, 저장 형식 변환의 복구·히스토리를 포함합니다.
- Windows 릴리즈 창에서 마우스로 색 선택·그리기·도구 복귀·입력란 포커스 해제,
  배경 변경, 도구/색/그림 재시작 복원과 오류창 재열기·종료를 확인했습니다.
  S 없이 종료한 PNG와 새 프로세스에서 다시 출력한 PNG가 정확히 같았으며,
  이미 최신 PNG가 있으면 종료 시 재인코딩을 생략하는 것도 확인했습니다.
- 전체 fmt·Clippy 및 자산을 포함한 DX 릴리즈 빌드를 통과했습니다.
- NVIDIA GeForce RTX 3080의 Vulkan과 DirectX 12에서 GPU 결과를 읽어 타일 한도 초과,
  음수 좌표·회전·보기 반전·진행 획 취소 복원을 확인했습니다. 지연 성능 측정은 아닙니다.
- **물리 펜의 색상환·두 버튼 조합은 사용자 검수가 남아 있습니다.** Windows/드라이버가
  두 버튼을 독립 신호로 주지 않는 기종은 드라이버에서 중간/오른쪽 클릭 또는 Space/Alt
  매핑이 필요할 수 있습니다. 모든 기기의 자동 지원을 보장하지 않습니다.
- 이번 설치·업데이트 설치, 다른 DPI·모니터, 장시간 작업 검수는 별도입니다.
  로컬 설치본은 교체하지 않았습니다. Linux/macOS 배포와 게시자 코드 서명은 포함하지 않습니다.
