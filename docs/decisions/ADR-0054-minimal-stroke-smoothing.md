# ADR-0054 — 선택 가능한 최소 선 보정

문서 정리 기준 시각: 2026-09-09T18:52:14+09:00

## 결정

`input::StrokeSmoother`는 위치만 보정하는 고정 메모리의 인과적 one-pole filter다.
도구별 세션 설정 0~100을 Begin에서 고정한다. 기본 0은 정확한 bypass이고 최대 강도는
20ms 시간상수다. **20ms는 측정한 종단 지연이나 성능 보장이 아니다.** 보정 자체가 위치 끌림을
추가하며, OS 입력/렌더 지연 또는 입력 유실의 해결책으로 제시하지 않는다.

Begin/End는 실제 전달된 끝점을 유지한다. End에서 한 번의 직선 연결을 하므로 강한 보정의
끝부분에 모서리가 생길 수 있다. 곡선 예측/지연 catch-up은 이번 최소 기능 밖이다.
시퀀스/시간/장치/viewport 이상과 긴 입력 간격은 원본 위치에 재정렬한다. Cancel은 즉시 reset.
필압·버튼·축·phase는 바꾸지 않고 새로운 샘플도 만들지 않는다.

## 실시간·저장 일치

native의 승인된 **그리기 입력**을 live GPU dab 평가와 저장용 sample 보존 전에 한 번만 보정한다.
선택/이동/스포이트는 통과시키지 않는다. raw 입력 계측은 보정 이전에 유지한다.
저장되는 스트로크 sample은 보정된 평가 입력이며 재열기에서는 다시 보정하지 않는다.
그러므로 이번 기능에 새 brush preset wire나 engine version을 추가하지 않는다.
향후 원본 입력으로 보정을 재편집하는 기능은 이 저장 방식을 역산해 제공할 수 없다.

하드웨어 지우개는 기억된 Eraser 설정의 보정을 복사한다. UI 선택 도구는 변경하지 않는다.
활성 보정에 비유한 좌표가 들어오면 부분 stroke의 GPU 결과를 취소하고 저장하지 않으며
새 clean Begin을 요구한다. 일반 Cancel/입력 discontinuity도 소유한 보정 상태와 함께 폐기한다.

검증은 off identity, batching/끝점/필압 불변과 live dab 입력/저장 재생 일치, 별도 프로세스
재열기의 픽셀/PNG를 대상으로 한다. 물리 펜 감각과 실제 화면 지연은 별도 미검증 항목이다.
추가 dependency 없음.
