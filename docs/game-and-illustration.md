# 일러스트레이션과 게임 아트의 공통 편집기

## 목표

Clip Studio Paint를 일러스트레이션과 게임 제작 작업에서 대체할 수 있는 편집기로 발전시킨다.
Krita·Photoshop·Aseprite의 작업 흐름을 비교하되 제품의 전체 기능 목록을 복제하지 않는다.
사용자 확인에 따라 래스터 애니메이션은 이제 구현 범위에 포함한다. 기존 W0–W5는
일러스트 완성 gate로 유지하며 픽셀아트 전용 제품으로 방향을 바꾸지 않는다.

## 필요한 작업

| 작업 축 | 끝까지 가능해야 하는 일 | 별도로 다룰 영역 |
|---|---|---|
| 일러스트 | 러프·선화·밑색·명암·부분 수정·참조색·완성 출력 | wet brush, 광범위 사진 보정, 벡터 편집 |
| 형태 수정 | 선택한 그림과 그룹의 선화·밑색·그림자를 함께 이동·회전·크기 조절 | mesh/liquify는 기본 affine 다음 |
| 게임 정지 아트 | 투명 PNG, 반복 타일, 기준 크기와 배율별 출력, 기존 PNG/NTDR 짝 유지 | Godot addon·범용 PSD 호환은 별도 |
| 래스터 애니메이션 | 프레임/셀 만들기·복제·삭제·전환, 시간/재생, 어니언 스킨, 저장/재열기 | 뼈대 리깅·3D·영상 편집은 현재 목표 아님 |
| 게임 애니메이션 산출 | 프레임 순서/시간과 출력 영역을 보존하는 스프라이트 시트·메타데이터 | GIF/APNG·고급 atlas packing은 우선하지 않음 |
| 반복 사용 | 취소/Undo·원본 보존·저장 실패 복구, Windows/웹 공유 코어 | 물리 펜·고주사율은 별도 실제 장치 검증 |

## 구현 순서와 현재 작업

1. 공통 마무리: Screen/Add/Overlay, 원본과 별개의 크기 지정 PNG, 참조창 색 채취.
2. 그룹 단위 형태 수정: 원본 고정, 공통 pivot, 모든 대상의 원자적 preview/commit/Undo.
3. 래스터 애니메이션: 실제 문서·셀·프레임의 소유권과 지속 형식부터 확정하고
   프레임 편집→재생/어니언→시트 출력을 같은 코어에 연결한다. UI만 프레임처럼 보이는
   방식이나 웹 전용 별도 작품 형식으로 완료 처리하지 않는다.
4. 비파괴 마무리와 부드러운 선택: layer mask·fractional selection은 서로 다른 개념이다.
   모든 그림 소비 경로와 저장된 획 재생을 함께 바꾸는 독립 변경으로 검증한다.

기능 구현 목록과 검증 상태는 [비교 감사](research/drawing-workflow-gap-audit.md)에 연결한다.
없는 기능을 설치판에서 쓸 수 있다고 쓰지 않는다. 현재 추가 기능은 로컬 구현/검증 중이며
이 문서 자체는 게시·릴리즈·설치본 교체를 의미하지 않는다.

## 구현 묶음과 다음 경계

이번 묶음에는 Screen/Add/Overlay, 참조창 스포이트, 그룹 affine 변형,
축소 PNG 출력, 단일 트랙의 layered-cel 애니메이션과 스프라이트 시트 출력을 구현했다.
프레임별 레이어와 표시 시간은 같은 `.ntdr` 문서에 저장한다. 어니언과 재생 커서는
작품 픽셀에 섞이지 않는 보기 상태다. 세부 동작과 제한은
[애니메이션 설계](animation-design.md), [출력](animation-export.md),
[네이티브 통합](native-animation.md)에 기록한다.

지속 래스터 마스크와 0–255 선택 coverage/feather를 후속 구현에 추가했다.
마스크는 원본 RGBA와 분리된 R8 타일을 저장하며, 선택 feather는 세션의 부드러운
편집 범위다. 둘은 clipping/alpha lock과 별개다. [마스크 계약](layer-mask-design.md),
[동작과 제한](layer-masks.md), [통합 검증 기록](workflow-expansion-validation.md)을 따른다.
소스 연결과 자동 불변식 검증을 실제 앱의 그리기·저장·프로세스 재시작·재열기
완료로 간주하지 않는다. 새 마스크/feather의 해당 runtime 증거는 통합 검증 단계에서
별도로 기록한다. 그룹 마스크·마스크 단독 변형·외형 보존 merge, 공유 배경 트랙,
애니메이션 이름 구간, 셀 재사용 UI와 GIF/APNG도 이번 기본 애니메이션 범위 밖이다.
따라서 이 묶음이 Clip Studio의 모든 일러스트 작업을 대체했다는 뜻은 아니다.

현재 [웹 마스크·feather 조작과 재열기](mask-web-acceptance.md)는 확인했다.
네이티브는 파일 보존 검사와 별개로 [메뉴 뒤 마스크 표시 문제](research/native-mask-presentation.md)가
남아 있어 안정적인 Windows 시각 작업 완료를 선언하지 않는다.

## 최적화

기능을 숨기거나 그림의 정확도를 낮춰 속도를 얻지 않는다. CPU 합성·저장/출력·브라우저
메인 스레드·GPU 표시를 분리 측정한다. 동일 fixture의 전후 픽셀 일치와 p50/p95/p99를
함께 기록하고, 희소 그림뿐 아니라 겹친 레이어에서도 퇴행을 확인한다.

애니메이션 캐시는 현재 프레임·필요한 이웃 프레임 중심으로 제한하며, 모든 프레임의
전체 합성을 매번 다시 하거나 GPU만 원본으로 두는 설계를 피한다.

희소 합성 최적화의 전후 픽셀 해시와 release 측정값은
[측정 기록](measurements/composite-sparse-2026-10-28.md)에 있다.
CPU 합성 시간과 물리 펜 지연을 구별한다.
