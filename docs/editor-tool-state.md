# 도구 상태 저장

상태: 구현 및 핵심 회귀 검사 통과. 설치본은 교체하지 않는다.

## 의미

- 프로젝트를 열면 그 프로젝트에서 마지막으로 사용한 도구 설정을 우선 복원한다.
- 설정이 없는 기존/새 프로젝트는 글로벌 마지막 사용값을 가져온다. 글로벌 값도 없으면
  검은색 펜 / 10px / 불투명도 100%부터 시작한다.
- 새 프로젝트가 처음 가져온 설정은 해당 프로젝트에 고정한다. 다른 프로젝트에서 색을
  바꾼 뒤 돌아와도 그 값에 따라 바뀌지 않는다.
- 사용자가 도구/설정/색을 실제 변경하면 프로젝트 값과 글로벌 마지막 사용값을 함께 저장한다.
  프로젝트를 열어 복원하는 행위만으로 글로벌 값을 바꾸지는 않는다.
- 명시적으로 저장하면 설정을 변경하지 않았더라도 현재 값을 프로젝트와 앱 양쪽에 기록한다.
  따라서 예전 파일을 열고 저장한 다음 새 그림을 만들면 방금 저장한 파일의 도구값을 이어받는다.
- Save As는 프로젝트의 설정도 복사한다. 도구 변경과 설정 복원은 Undo/Redo 대상이 아니며
  작품의 변경 표시, 픽셀, 출력 PNG, history head를 바꾸지 않는다.

## 저장 범위

- 선택된 도구와 연필 템플릿(2H/2B).
- 연필 2H/2B, 펜, 브러시, 지우개 각각의 크기·불투명도·필압 옵션·최소 비율·경도·보정.
- 전경색과 배경색. 스포이드로 확정한 색도 포함한다.
- 채우기 참조/허용오차/틈 닫기/확장/AA, 선택 조합 모드.

Alt·펜 버튼으로 누르고 있는 임시 스포이드/그랩, 뒤집은 펜의 임시 지우개는 도구 선택을
덮어쓰지 않는다. 해당 입력이 끝난 뒤 복귀할 본래 도구만 저장한다.

## 저장 경계

### 활성 레이어는 프로젝트에만 보존

마지막으로 선택한 래스터는 `state/editor_active_layer`의 `NYLAYER1` + little-endian
128비트 ID, 총 24바이트로 저장한다. 앱 공통 도구 설정에는 섞지 않는다. 다른 작품의
우연히 같은 ID인 레이어를 선택하거나 레이어 선택만으로 그림/Undo 이력을 바꾸지 않는다.

웹의 복구 Worker와 `.ntdr` 다운로드, 데스크톱의 설정 작성 큐는 같은 레코드를 쓴다.
데스크톱은 최신 선택 하나만 대기시키고 종료 시 drain한다. Save As는 이 레코드도 복사한다.
재열기에는 현재 레이어 트리에 존재하는 래스터인지 검증한다. 기록이 없거나 삭제된 ID이면
기존 기본 레이어 선택으로 돌아간다. 잠금/숨김 레이어도 유효한 마지막 선택이면 복원하며,
임의로 다른 레이어에 칠하지 않는다.

손상·미지원 버전은 비치명적 안내와 함께 원본 레코드를 보존한다. 그 때문에 그림 열기를
차단하거나 설정을 초기화하지 않는다. 이 변경은 작품 포맷/픽셀/히스토리 스키마를 바꾸지 않는다.

### 도구 설정

`state/editor_tool_state`는 프로젝트 저장소의 선택적 application-owned 레코드다. 새 기록은 `NYTOOL02`
헤더의 고정 87바이트 값이며 읽을 때 길이, enum, 슬롯 연계, 크기/불투명도/보정/채우기 범위를
검사한다. 저장소 읽기는 복사 전 512바이트 상한을 검사한다. 작품 포맷 버전과 이력에는
관여하지 않고, 기존 `state` 테이블 복사 방식에 따라 Save As/컨테이너 이전에도 보존된다.
기존 `NYTOOL01` 85바이트 기록은 채우기 참조와 허용오차를 당시의 공유 참조와 허용오차에서
복사해 복원한다. 새 프로젝트의 채우기 기본값은 보이는 모든 레이어/허용오차 16이다.

글로벌 값은 사용자 workspace 설정 옆 `workspace.tools`에 동일 형식으로 저장한다.
`NAYATI_LAYOUT_PATH`가 있으면 그 경로의 확장자를 `.tools`로 바꾼 파일을 사용한다.
형식이 손상되었거나 미래 버전인 파일/레코드는 덮어쓰지 않고 해당 실행 동안 저장을 막는다.
읽기/쓰기 실패는 비치명적 알림으로 표시하며 그림 열기나 그림 저장 실패로 승격하지 않는다.

UI/render 경로는 최신 상태 하나짜리 메일박스만 교체한다. 기존 프로젝트 작성 스레드가
이를 꺼내 별도 트랜잭션으로 저장한다. 종료/Save As의 작성 스레드 drain도 이 값을 처리한다.
글로벌 파일은 sibling 임시 파일 후 원자적 교체를 사용한다. 설정 작업 큐는 늘어나지 않는다.

웹도 같은 `NYTOOL02` 코덱과 우선순위를 사용한다. 앱 마지막 값은 같은 origin의
`localStorage`에 `nyatidraw-web-ui-v1-tools` 키로 Base64 저장한다. 다른 도메인·브라우저·기기와
동기화되는 설정은 아니다. 파일 및 브라우저 복구 저장은 기존 Worker의 `.ntdr` 기록을 사용한다.
Worker 내부 전달 형식 `NYWORK04`는 독립 채우기 참조/허용오차를 전달한다. 기존 `NYWORK03`
복구 패킷은 공유 값을 채우기 설정에도 복사해 읽는다. `.ntdr` 도구 레코드도 위의 새 버전으로
기록한다. 프런트엔드와 Worker는 함께 빌드한다.
손상된 앱 설정은 보존하고 해당 실행의 덮어쓰기를 중단한다. 설정 저장 불가와 그림 저장 실패는
별도로 취급한다.

**전역 필압 매핑은 앱 레벨만** 사용한다. 위 프로젝트별 도구 설정에 추가하지 않는다.
[필압 매핑 설계](research/pen-pressure-mapping.md)를 참조한다.

신규 브러시 설정의 크기·불투명도 필압 최솟값은 모두 0이다. 이는 전체 불투명도를
0으로 설정한다는 뜻이 아니며, 축별 필압 적용 스위치는 별개다. 기존 파일/앱에 저장된
최솟값은 덮어쓰지 않는다. 역사적 브러시 프리셋과 기록된 획 알고리즘도 변경하지 않는다.

## 이름 있는 브러시 프리셋

Subtool 패널의 `+`는 현재 그리기 도구를 새 이름으로 저장하고 `…`는 관리 조작을 연다.
목록은 선택한 연필/펜/브러시/지우개의 변형만 표시한다. 연필은 2H/2B도 기록한다.
이름 변경과 별도로 현재 설정으로 갱신/삭제는 명시적 확인을 거친다. 작업 중 크기나 농도를
바꾸어도 저장한 원본은 자동 갱신하지 않는다. 기존 기본 도구/연필 템플릿은 계속 사용할 수 있다.

프리셋은 크기·불투명도·크기/농도 필압 스위치와 최소값·경도·보정만 캡처한다.
색, 전역 필압 매핑, 문서/레이어/선택/작품 이력은 포함하지 않는다. 적용은 하나의 도구 명령으로
처리하며 진행 중인 획에는 적용하지 않는다. 다음 Begin부터 설정을 고정하고 그림 변경 표시나
Undo 항목을 추가하지 않는다. 프로젝트를 여는 기존 도구 상태 우선순위는 그대로다.

앱 공통 라이브러리는 데스크톱 `workspace.brushes` (`NAYATI_LAYOUT_PATH`의 `.brushes` sibling),
웹은 같은 origin의 localStorage `nyatidraw-web-ui-v1-brush-presets`에 저장한다.
공유 `NYBRSH01` 코덱은 최대 64개, 이름 UTF-8 96바이트, 레코드 전체 7,049바이트로 제한한다.
데스크톱은 기존 최신 설정 메일박스/작성 스레드와 종료 drain, sibling 임시 파일 교체를 쓴다.
라이브러리는 작품 파일에 포함되거나 다른 브라우저/기기와 동기화되지 않는다.
읽기 실패/손상/미지원 버전은 원본을 보존하고 실행 중 저장을 막으며, 저장 실패는 그림 저장과
별도 알림이다. 프리셋 선택 목록을 읽기 위해 UI polling마다 파일을 다시 읽지는 않는다.

검증 결과: 핵심 설정 round-trip/잘못된 레코드 거부 1개, scratch 라이브러리의 최신 메일박스
저장과 재읽기/원본 보존·다른 도구/색/프로젝트 보존 1개 통과. 데스크톱/shared UI 및 WASM web
Clippy도 통과했으며 기존 vendor wry lifetime 경고는 남아 있다.

격리된 Edge 프로필과 별도 localhost origin에서 Dioxus 웹/Worker 빌드를 확인했다.
펜 17.3px/63%를 이름 붙여 저장한 뒤 5px/100%로 바꾸고 재적용했을 때 원래 값이 복원됐다.
연필 도구에서는 펜 프리셋이 숨겨졌고, 브라우저 프로세스를 완전히 종료하고 같은 시험용
프로필로 재시작해도 프리셋과 설정이 유지됐다. 이름 변경, 삭제 취소의 원본 보존,
삭제 확정도 UI로 확인했다. 사용자 작품과 실제 브라우저 프로필은 사용하지 않았다.
이 검증은 데스크톱 창 조작·물리 펜·iPad Safari 합격을 뜻하지 않는다.

## 이번 웹·데스크톱 보완 검증

- 프로젝트/앱 우선순위와 양쪽 저장을 다룬 핵심 검사, 기존 손상 레코드 보존 검사:
  desktop 도구 상태 3개, project-web 10개 통과. 그림 없는 기존 파일도 저장 시 기본 도구
  레코드를 추가하는 경우를 포함한다.
- native desktop/project-web 및 WASM web/worker Clippy 통과. 기존 vendor wry의 lifetime
  경고는 남아 있다. Dioxus 디버그 웹 빌드 및 Worker 빌드 성공.
- 격리된 Edge 프로필에서 2B/17px/63% → 펜 선택 → 브라우저 프로세스 종료/재시작 →
  연필 복귀 시 2B/17px/63% 복원. 새 그림에도 설정 상속 확인.
- 앱 마지막 값을 펜/23px로 바꾼 뒤 이전 `.ntdr`을 가져오면 파일의 2B/17px/63%가 우선한다.
  가져오기만으로 앱 값을 덮어쓰지 않으며, Save 시 앱 값도 파일의 현재 값으로 갱신된다.
- 웹에서 실제 마우스 획을 만든 시험용 `.ntdr`을 내려받아 별도 native probe 프로세스에서
  다시 열었다. native/web artwork root 일치 확인. 사용자 작품은 사용하지 않았다.
- 일반 UI 드래그는 텍스트를 선택하지 않는다. 숫자 입력은 수정 가능하며 레이어 이름은
  읽기 전용일 때 선택 차단, 이름 수정 중에는 전체 선택 가능함을 확인했다.
- 위 브라우저 검증은 Windows Edge이며 실제 iPad Safari 길게 누르기·물리 펜 검증을 뜻하지
  않는다. 공용 CSS에 `-webkit-user-select`와 `-webkit-touch-callout`을 적용했다.
- 이후 alpha.15 공개 배포와 공개 웹 검증을 완료했다([배포 기록](releasing.md#alpha15-배포-확인)).
  로컬 설치본은 교체하지 않았다. 이번 desktop 변경은 핵심 검사/컴파일로 검증했으며
  desktop 창에서 Save/Save As를 재시험하지는 않았다.

## 이전 데스크톱 검증 기록

- 추가한 핵심 회귀 사례: 브러시 설정 round-trip/잘못된 범위 거부, 잘못된 optional 설정이
  프로젝트 열기를 막거나 원래 레코드를 덮어쓰지 않는지, Save As 설정 보존.
- 위 사례와 desktop 컴파일/Clippy를 통과했다. alpha.12 desktop 핵심 회귀 검사는 54개 통과,
  별도 실행이 필요한 기존 4개는 제외했다.
- `cfg(test)`에서는 글로벌 설정 접근을 비활성화하여 scratch 프로젝트 시험이 실제 사용자
  설정을 읽거나 바꾸지 않는다. 별도 앱 smoke 실행은 전용 workspace 경로도 지정해야 한다.
- 자산 포함 release 앱(Windows/RTX 3080/DirectX 12), 임시 프로젝트·설정 경로에서
  2B/20px/선택 색 변경 → 획 입력 → 지우개/연필 전환 → 종료 → 별도 프로세스 재열기를
  마우스로 확인했다. 그림 root, 2B/20px/선택 색과 바깥 단색 배경이 복원되었다.
- 두 프로젝트 간 전역 기본값의 UI 전환, UI Save As, Undo/Redo 중 도구 유지,
  임시 물리 펜 도구 복귀는 아직 창에서 확인하지 않았다. Save As 레코드 보존은 핵심 검사로 확인했다.
