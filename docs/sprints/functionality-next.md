# 기능 완성 우선 후속 작업

문서 정리 기준 시각: 2026-09-09T18:52:14+09:00

> 실행 순서 변경: [일러스트 워크플로우 감사와 W0~W5](../illustration-workflow.md)가 현재 우선순위다.
> 이 문서의 F1~F3a는 구현·검증 기록으로 보존한다. F3b/병합은 자동 후속 작업이 아니며,
> 러프→선화→밑색→명암→마무리에서 실제로 막히는 지점에 맞춰 재배치한다.

기준 배포판은 `v0.1.0-alpha.8`이다. 다음 작업은 추가 성능 최적화보다
Godot 프로토타입 그림을 끝까지 편집하는 데 필요한 기능 연결을 우선한다.
입력 유실, 저장 손상, 크래시 등 작업을 막는 결함은 계속 우선 수정한다.
아래 순서는 기존 Sprint 2/3의 사용자 기능 보완 순서이며, 미검증 성능·하드웨어
gate를 완료로 바꾸거나 벡터·애니메이션 범위를 앞당기지 않는다.

## F1 — 레이어 작업 완성: 현재 구현 범위

- 활성 래스터 레이어 복제: 같은 그룹에서 원본 바로 위에 삽입하고 복제본 선택.
- 이름에 ` 복사`를 붙이며 128자 제한 유지. 가시성·잠금·참조·불투명도 속성 복사.
- 페이지 밖 signed tile도 모두 복사. 픽셀 객체는 불변 공유하고 이후 편집은 독립.
- 메타데이터와 픽셀을 기존 단일 구조 변경 트랜잭션으로 함께 저장.
  Undo/Redo는 레이어 트리와 타일 상태를 함께 복원한다.
- 래스터와 그룹의 불투명도: 0~100 정수 입력. Enter/포커스 이동으로 입력을 확정하고
  변경된 값만 명령 전송. 0%는 숨김/삭제와 별개인 투명 합성 상태다.
- 레이어 미리보기 클릭으로 활성 레이어 선택. 기존 드래그 이동은 유지.
- 그룹 전체 복제, 병합, 클리핑 마스크는 이번 범위 밖.

검증은 핵심 artwork 불변식 테스트와 워크스페이스 검사, DX release build로 한다.
자동 테스트는 UI 레이아웃에 추가하지 않는다. 검증 결과는 이 문서 아래에 기록한다.

## F1b — 사각형 선택과 이동: 피드백 반영 우선 작업

- F2보다 먼저 사각형 선택·선택 픽셀 이동·체크무늬 좌표 정렬을 구현한다.
- `g` 순환: 화면 이동(손) → 선택 픽셀 이동(화살표) → 마법봉 → 올가미 → 사각형 선택.
- 사각형은 어느 방향으로 끌어도 동일한 픽셀을 선택하고 시작/끝 픽셀을 포함한다.
  한 점 클릭은 1픽셀 선택. 기존 bounded polygon mask 경로를 재사용한다.
- 선택 이동은 선택이 없을 때 레이어 전체를 움직이지 않고 거부한다. 이동 중 안내선,
  버튼을 놓으면 픽셀 이동 확정·선택 해제. Cancel/좌표 오버플로/viewport 변경은 거부한다.
- 결과 픽셀·Undo/Redo는 기존 원자적 편집 저장 경로를 사용한다.
- 현재 마스크 자체는 페이지 내부 제한이다. 페이지 밖 새 선택, 이동 중 픽셀 미리보기,
  선택을 유지하며 연속 이동하기는 후속 F3에서 함께 다룬다.

### 체크무늬 판단 근거

[Krita 공식 설명](https://docs.krita.org/en/reference_manual/preferences/display_settings.html)은
체크무늬가 팬·줌에 따라 움직이는 방식과 화면 고정 방식 모두를 지원한다고 설명한다.
[Aseprite 설정 문서](https://www.aseprite.org/docs/preferences/)도 투명 배경의 칸 크기·색상과
픽셀 격자를 별도 설정으로 구분한다. 따라서 화면 고정이 반드시 오류인 것은 아니지만,
NyatiDraw는 게임 에셋 편집 시 문서 좌표와의 대응을 위해 문서 원점 기준 16픽셀 칸을 택한다.
페이지 내부만 표시하고 바깥 검은 테두리·중립 배경과 export 픽셀은 변경하지 않는다.
극단적인 축소의 격자 aliasing 완화와 사용자 설정은 후순위다.

## F2 — 실수 방지와 색상 작업

1. 레이어 잠금 토글과 모든 픽셀 변경 경로의 일관된 잠금 검사 (현재 구현).
2. 전경/배경색 교환 및 색상 선택 흐름 정리 (현재 구현).
3. 스포이트의 활성/참조/보이는 전체 레이어 샘플링과 페이지 밖 좌표 지원 (현재 구현).

완료 조건: 잠긴 레이어는 브러시·지우개·채우기·변형·비우기로 변경되지 않으며,
색상 작업 결과가 저장된 그림과 PNG에 일치한다.

### F2a — 래스터 픽셀 잠금 의미론

- 레이어 패널의 참조 버튼 옆 자물쇠로 활성 래스터의 잠금을 토글한다.
  각 잠긴 래스터 이름 아래에도 자물쇠를 표시한다. 그룹 자체 잠금은 후속 범위다.
- 잠긴 래스터의 브러시/펜/연필/지우개, 채우기/그라데이션, 선택 이동/변형, 비우기는
  차단한다. 실시간 경로는 입력 phase를 소비하되 GPU preview/저장 작업을 생성하지 않는다.
  writer는 닫힌 스트로크 대상의 잠금을 재검사하고 불일치 시 저장 없이 fail-stop한다.
- 잠긴 래스터 삭제 및 이를 포함한 그룹 삭제도 차단한다. 먼저 잠금을 해제해야 한다.
- 선택만 만들기, 참조로 읽기, 이름/가시성/불투명도/순서 변경은 허용한다.
  레이어 복제는 잠금 속성도 복사하므로 복제본을 그리려면 잠금을 해제해야 한다.
- 문서 전체 페이지 크기 조절/Crop 좌표 재정렬 및 Undo/Redo는 허용한다.
  잠금은 편집 실수 방지이지 보안 권한이나 history 이동 금지가 아니다.
- lock/unlock 자체도 기존 레이어 구조 변경 history와 동일하게 저장·Undo/Redo된다.
  이미 저장되는 `LayerNode.locked`를 사용하므로 schema migration은 필요 없다.

### F2b — 전경/배경색과 스포이트 의미론

- 상단 겹친 색상 버튼 또는 `X`로 전경/배경을 교환한다. 배경색은 흰색으로 시작한다.
  색상 패널과 최근 색은 전경을 편집한다. 배경을 편집하려면 교환→색 선택→교환한다.
  두 색과 최근 목록은 세션 상태이며 프로젝트 history/파일에 저장하지 않는다.
- 스포이트는 별도 `I` 도구다. 마우스/펜을 놓는 위치의 픽셀을 읽고 전경색만 바꾼다.
  사용 후 자동으로 이전 도구로 돌아가거나 Alt 임시 전환하는 기능은 아직 없다.
- 활성 레이어는 가시성·잠금·레이어 불투명도를 적용하지 않은 원본 픽셀을 읽는다.
  참조 레이어 및 보이는 전체 레이어는 문서의 가시성, 중첩 그룹과 불투명도를 적용한다.
  session-only Solo는 반영하지 않는다. 참조 레이어가 없으면 명시적으로 거부한다.
- 페이지 밖 signed 좌표도 읽는다. 체크무늬, 페이지 테두리, 선택 표시 및 UI는 색상에
  섞이지 않는다. 전체 이미지를 펼치지 않고 해당 픽셀만 레이어별로 합성한다.
- 저장된 premultiplied linear RGBA8에서 alpha를 분리하고 sRGB로 변환한다.
  채취한 색의 alpha는 255이며 브러시 불투명도는 유지한다. 낮은 alpha의 8비트 양자화
  오차는 복원할 수 없다. 완전 투명한 픽셀은 안내 후 기존 색을 유지한다.
- 채취 자체는 픽셀·선택·history를 변경하지 않는다. 비동기 편집이 진행 중이면 새 색
  설정/교환은 busy로 거부하여 오래된 채취 결과가 이후 색상 명령을 덮지 않게 한다.

## F3 — 요소 재사용

선택 영역 복사/잘라내기/붙여넣기 → 붙여넣은 요소의 이동·확정/취소 → 필요한
래스터 병합 순서로 진행한다. 선택 mask·원본 위치·투명도·Undo 경계를 먼저 정한다.
시스템 클립보드는 Windows 어댑터에 격리하고 OS 타입을 문서 모델에 넣지 않는다.

완료 조건: 게임 캐릭터/소품 일부를 다른 위치에 재사용하고, 취소/Undo/재열기에서
원본과 결과가 손상되지 않는다.

### F3a — 선택 영역 클립보드: 현재 구현

- 버거메뉴의 복사/잘라내기/붙여넣기와 `Ctrl+C/X/V`를 연결한다. 기존 `X` 색상 교환과
  Ctrl+X를 구분한다. 텍스트/숫자 편집 컨트롤의 기존 키 이벤트 격리는 유지한다.
- 복사/잘라내기는 활성 래스터의 명시적이고 비어 있지 않은 선택 영역을 요구한다.
  숨김/불투명도/Solo/참조 합성이 아닌 원본 픽셀을 읽으며 선택의 구멍은 투명하게 둔다.
  선택 없음에서 전체 그림을 암묵적으로 복사하거나 잘라내지는 않는다.
- 복사는 history를 만들지 않는다. 잘라내기는 전체 변경을 먼저 계산하고 Windows
  클립보드 기록이 성공한 뒤 한 번의 durable commit으로 선택 픽셀을 지운다.
  실패하면 그림은 유지된다. DB 저장이 실패하면 클립보드에는 복사본이 있을 수 있지만
  편집 경로는 fail-stop하므로 이를 성공한 잘라내기로 보고하지 않는다.
- 붙여넣기는 활성 래스터 바로 위, 같은 그룹에 `붙여넣기`라는 새 래스터를 만든다.
  가시성 on, 불투명도 100%, 잠금/reference off. 레이어 생성과 픽셀은 한 Undo 단위다.
  활성 원본이 잠겨 있어도 새 레이어로 붙여넣기는 허용한다. 기존 레이어는 덮지 않는다.
- NyatiDraw 전용 클립보드는 원래 signed 위치와 linear premultiplied RGBA8 바이트를
  그대로 보존한다. PNG 형식도 함께 게시한다. 외부 PNG를 붙이면 원점 (0,0)에 놓는다.
  외부 앱이 PNG 없이 DIB/CF_BITMAP만 제공하는 경우는 아직 지원하지 않는다.
- 붙여넣기는 즉시 확정되고 기존 선택은 해제한다. 현재는 기존 변형 패널로 새 레이어를
  이동할 수 있다. floating preview, Enter/Escape 확정/취소, 자동 선택과 연속 드래그,
  페이지 밖 새 선택은 F3b다. 이번 구현을 해당 기능들의 완료로 간주하지 않는다.
- OS 타입은 desktop 어댑터에만 둔다. 픽셀 편집은 `paint-cpu::RasterFragment`,
  OS 교환은 `ArtworkClipboard` 경계로 분리한다. 시험 대역은 실제 사용자 클립보드를
  읽거나 비우지 않는다. 새 저장 schema나 신규 dependency는 없다.

### F3b/F3c — 다음 작업

1. 페이지 밖까지 선택 가능한 mask 좌표 구조, 붙인 요소 선택 유지 및 이동 미리보기.
2. 이동 확정/취소와 연속 이동, 취소/Undo 시 원본과 미리보기 분리.
3. 아래 래스터와 병합: 그룹/잠금/불투명도 경계와 저장·Undo 검증.

## 배포와 범위

각 묶음은 구현·저장·프로세스 재시작·재열기를 확인한 뒤 완료 처리한다.

설치본 또는 공개 alpha.8이 자동으로 갱신되었다고 간주하지 않는다.

  체크 칸 색상을 readback 대조(채널 오차 허용 2)했다. 기존 합성/복구 probe도 통과했다.
  표시 정확도 검사이며 p50/p95/p99 지연 측정 및 실제 창 표시 검증은 하지 않았다.
- DX 0.7.9 Windows release build와 asset bundling 통과. 설치본 갱신·태그/릴리스는
  수행하지 않았다. 실제 창에서의 도구 클릭/드래그 및 아이콘 시각 확인은 남아 있다.

## F2a 검증 기록

- 전체 workspace/all-features 테스트: 108 passed, 1 ignored (기존 scratch registry).
- core 테스트 2개 추가: 잠긴 상태의 브러시/지우개/채우기/이동 입력과 종료 직전 입력이
  GPU 작업 또는 저장을 생성하지 않음; 픽셀 편집/상위 그룹 삭제 거부가 원본과 history를
  보존함; 잠금 해제 후 편집 및 Undo로 잠금·픽셀을 복원하고 별도 프로세스에서 재열기.
- Clippy 전체 target/feature, fmt, diff whitespace 검사 통과.
- DX 0.7.9 Windows release build 및 asset bundling 통과.
  실제 창/펜 조작, 설치본 갱신, 릴리스는 수행하지 않았다.
- 이어지는 색상 교환·스포이트는 아래 F2b 기록을 참고한다. 선택 영역 재사용은 F3이다.

## F2b 검증 기록

- 전체 workspace/all-features 테스트: 110 passed, 1 ignored (기존 scratch registry).
- core 테스트 2개 추가 및 기존 색상 변환 불변식 확장: signed 좌표, 활성/참조/전체 합성,
  중첩 그룹 불투명도, 숨김·잠금 레이어 원본 읽기, 투명 픽셀, alpha 분리와 sRGB 변환.
- 합성 native gesture → writer 채취 → 채취 색으로 선택 영역 채우기 → 저장 → 별도
  프로세스 재열기에서 픽셀과 PNG 바이트가 일치했다. 채취 자체는 타일/선택/history를
  변경하지 않고, 채우기 Undo 대상은 채취 전 원본과 일치한다. 사용자 그림은 사용하지 않았다.
- Clippy 전체 target/feature, fmt, diff whitespace 검사 통과.
- DX 0.7.9 Windows release build 및 asset bundling 통과. 새 의존성/저장 schema는 없다.
- 실제 창의 클릭·단축키·물리 펜 acceptance는 남아 있다. 설치본 갱신, 커밋, push,
  태그/릴리스는 수행하지 않았다. 다음 기능 묶음은 F3 선택 영역 복사/잘라내기/붙여넣기다.

## F3a 검증 기록

- 전체 workspace/all-features 테스트: 113 passed, 1 ignored (기존 scratch registry).
- core 테스트 3개 추가: 선택 구멍·alpha·signed 좌표와 제한 초과 시 실패 원자성;
  전용 클립보드 크기/좌표/픽셀 검증과 PNG decoder 한도; clipboard 실패/잠금 거부가
  원본을 유지하고 cut/paste의 새 레이어·픽셀·Undo/Redo·PNG가 별도 프로세스 재열기에서 보존됨.
- 실제 OS 클립보드를 읽거나 비우지 않고 memory adapter로 데이터 포맷과 writer를 검증했다.
  Windows API 호출·UI 단축키·외부 앱 왕복은 컴파일 연결까지만 확인했으며 수동 검증이 남는다.
- 전체 target/feature Clippy, fmt, diff whitespace 검사 통과.
- DX 0.7.9 Windows release build와 asset bundling 통과. 기존 third-party 경고만 남는다.
- [ADR-0050](../decisions/ADR-0050-artwork-clipboard.md)에 형식, 메모리 소유권, 실패 순서와
  DIB 미지원 범위를 기록했다. 설치본·공개 릴리스·Git 시각·커밋·태그는 변경하지 않았다.
- 다음은 F3b 선택/이동 상태 개선이다. F3 전체 완료로 처리하지 않는다.
