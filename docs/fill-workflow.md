# 채우기 작업 흐름

## 비교와 선택

비교는 공식 사용 설명서를 기준으로 한다. 두 제품의 실제 펜 조작 비교나 동일 알고리즘
구현을 뜻하지 않는다.

| 작업 | Krita | Clip Studio Paint | NyatiDraw의 이번 변경 |
|---|---|---|---|
| 빈 밑색 레이어에서 선화를 읽기 | 현재/전체/색상 라벨 레이어 참조 | 현재/다른 레이어 참조 세부도구 | 다른 레이어도 참조 / 현재 레이어만 / 참조 레이어만을 세부도구로 표시 |
| 허용 오차와 작은 틈 조절 | Threshold와 Close Gap 분리 | Color Margin과 Close Gap 분리 | 허용 오차·틈 닫기에 숫자와 드래그 슬라이더 제공 |
| 선 아래 빈틈 줄이기 | Grow 및 어둡거나 불투명한 경계에서 확장 중지 옵션 | Area Scaling | 기존 제한적 확장을 '선 밑으로 확장'으로 표시. 정교한 경계 추적은 추가하지 않음 |
| 선택 전체 칠하기 | Current Selection 모드 | 선택 영역 채우기 명령 | 버킷과 구분한 '선택 전체 채우기' 버튼 및 해제 버튼 |

## 동작 계약

- 투명도 잠금 중에는 연결된 기존 색 영역만 재칠하고 alpha와 경계 선을 보존한다.
  선 밑 확장·최소 1px 빈틈 보정은 적용되지 않으며 해당 입력을 비활성화한다.
  저장된 옵션 값은 유지하므로 잠금을 해제하면 다시 사용할 수 있다.
- 앱/파일 어디에도 설정이 없을 때만 채우기는 전체 보이는 그림 참조, 허용 오차 16,
  틈 닫기 0, 확장 1px로 시작한다. 16은 작은 색 차이를 허용하는 NyatiDraw의 초기 선택이며
  다른 제품의 기본값을 주장하지 않는다. 원래 선이 약하면 오차를 낮춰야 한다.
- 선택한 현재 레이어에만 쓴다. 참조 대상은 경계를 읽는 범위다. 세부도구 변경은 레이어를
  만들거나 활성 레이어를 바꾸지 않는다. 새 문서는 여전히 투명 래스터 하나다.
- 채우기의 참조와 허용 오차를 마법봉/스포이트의 기존 설정에서 분리한다. 세부도구를 바꿔도
  틈 닫기·확장 값을 초기화하지 않는다. 이전 파일/앱 상태의 명시적 설정은 그대로 옮긴다.
  [설정 저장과 버전 호환](editor-tool-state.md)을 따른다.
- 현재 채색 대상 이름과 색을 표시한다. 대상 잠금/숨김 또는 참조 미지정은 속성에 안내한다.
  참조 없음/선택 밖 클릭/자원 한도 오류는 복구 방법을 알려주며 자동으로 다른 참조로
  바꾸거나 부분 채우기를 확정하지 않는다.
- 버킷·선택 전체 채우기·그라데이션은 숨긴 대상/상위 그룹에는 쓰지 않는다. 공용 편집
  경로에서 거절하므로 웹/데스크톱 모두 픽셀·선택·Undo가 그대로 남는다. Solo는 저장된
  숨김 상태를 바꾸지 않으므로 먼저 레이어의 표시를 켜야 한다. 불투명도 0%와 투명도 잠금은
  편집을 막지 않고 결과가 보이지 않거나 기존 불투명 영역에만 적용되는 이유를 안내한다.
  참조 안내도 숨긴 상위 그룹과 불투명도 0%를 포함해 실제 읽을 수 있는 선화인지 확인한다.
- 클리핑된 참조 선화는 같은 부모의 원래 순서에서 묶인 아래 기준 레이어가 표시되고
  불투명도가 0%보다 높아야 한다. 기준 레이어 없음·숨김·0% 또는 표시할 기준 자식이 없는
  그룹은 속성 안내에서도 읽을 수 있는 참조로 계산하지 않는다. 실제로 비어 있는 래스터의
  픽셀까지 속성 정보만으로 판정하지는 않는다. 안내는 참조 범위나 채우기 알고리즘을 바꾸지 않는다.
- 마지막 채색 대상은 프로젝트별로 보존한다. 재열기 때 그 래스터가 여전히 있으면
  활성 레이어로 복원하고, 삭제된 대상이면 기존 기본 선택으로 돌아간다. 앱 공통 도구
  설정에는 레이어 ID를 넣지 않으며 레이어 선택만으로 Undo나 출력 픽셀은 바꾸지 않는다.
- 버킷은 연결 영역만 채우며 기존 선택은 통과 불가능한 경계다. '선택 전체 채우기'는
  선 경계와 관계없이 선택 마스크 전체를 칠하는 별도 명령이다. 현재 색을 linear premultiplied
  RGBA로 변환해 기존 공용 편집 경로에 전달한다. 선택은 유지하며 한 번 Undo로 취소한다.
- 입력 수치는 우측 정렬하고 펜으로 조절할 수 있는 슬라이더를 함께 제공한다. 추가 옵션은
  접는다. 기존 `antialias` wire 필드는 유지하되 UI는 '최소 1px 빈틈 보정'이라고 부른다.
  이것은 fractional AA가 아니라 최소 한 픽셀의 선 밑 받침이다.

## 경계와 후속

이번 범위는 기본 버킷의 UX와 설정 보존이다. 기존 CPU 채우기 알고리즘, 선택 clip,
원본 보존, 자원 상한을 유지한다. 틈 닫기는 원본 선을 변경하지 않는 사각 closing이며
의도한 좁은 통로도 막을 수 있다. 선 밑 확장은 다른 연결 영역으로 번지지 않지만,
가는 반투명 선의 alpha를 이상적으로 재구성하지는 않는다.

드래그 여러 영역 채우기, 둘러싸서 자동 채우기, 미채움 쓸어 보정, 선 넘침 방지 브러시,
정교한 AA/어두운 경계 추적은 구현 완료로 표시하지 않는다. 기존 알고리즘 검토와
특허 검토 보류도 해제하지 않는다. [W3 후속](illustration-workflow.md#5-채색-생산성-후속-요구--계획-기록만-구현-보류).
