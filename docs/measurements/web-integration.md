# 웹 연동 검증

현재 작업 트리의 브라우저 연동 검증 기록이다. 공개 배포, 실제 펜, iPad Safari,
임의 SNS의 업로드 연동을 자동으로 보장하지 않는다. 사용자 작품 대신 격리된 프로필과
시험용 문서를 사용한다.

## 확인 기준

| 경로 | 확인할 결과 | 상태 |
|---|---|---|
| 일반 웹판 | 작업 저장 후 새로고침 복구 | 통과; 잠금 우회 없이 임베드 병행 |
| iframe 초기화 | 지정 캔버스·Pen·12.3px 반올림·빨강 및 패널 구성 | 통과 |
| 새 창/탭 | 팝업은 iframe 숨김 옵션과 무관하게 전체 UI 유지 | 통과; 완료 PNG 수신 후 창 닫힘 |
| PNG 반환 | 640×480 출력에 2,468개의 비투명 픽셀 도착 | 통과; 실제 브라우저 마우스 합성 입력 |
| 전송 실패 | 콜백 거절 및 12초 무응답 후 재시도 | 통과; 거절 전후 PNG 바이트 동일, 늦은 콜백이 창을 닫지 않음 |
| 취소 | 계속 그리기 또는 명시적 폐기 선택 | 통과; 호스트 확인 뒤 iframe 제거 |
| 저장 격리 | 일반 작업과 두 임베드를 동시 실행 | 통과; 기존 IndexedDB SHA-256과 localStorage 설정 동일 |
| 요청 검증 | 잘못된 session ACK 및 초기화 재전송 | 통과; origin/source 검사는 코드 검토, 별도 악성 출처 실험은 미실시 |
| 무단 iframe | 일반 웹판의 복구 그림을 노출하지 않음 | 통과; 시작 차단 및 복구 다운로드 버튼 없음 |
| 저장·재열기 | 임베드 NTDR을 별도 프로세스 native/web으로 다시 열기 | 통과; 그림 타일 존재 및 artwork root 동일 |

## 검증 환경과 산출물

- Windows, Microsoft Edge 154.0.4258.37 headless, WebGPU 활성화,
  Dioxus debug Web/Worker 빌드. 실제 펜·터치·Safari·Firefox·공개 HTTPS 배포는 미검증.
- 호스트 `127.0.0.1:8875`, 편집기 `127.0.0.1:8874`로 서로 다른 origin을 사용했다.
- 전체 패널은 1000px/1280px 폭에서 확인했다. 720×650의 최소 UI는 캔버스만 남기고
  우측 잘림 없이 그린 500개 비투명 픽셀을 반환했다. 모든 패널을 720px에 넣는 구성은
  지원 권장 크기가 아니며, 작은 화면에서는 필요한 패널만 선택한다.
- `cargo fmt --all -- --check`, Web/Worker WASM Clippy `-D warnings`, 두 JavaScript 구문 검사 통과.
- input 8개, project-web 10개, web-core 6개 핵심 테스트 통과.
- 로컬 증거는 무시되는 `output/playwright/embed-*`, `output/embed-*.log`에 있다.
  사용자 작품과 설치본은 변경하지 않았다. 이 기록은 릴리스/배포 완료 선언이 아니다.

## 경계

- iframe UI 설정은 배치/표시 옵션이며 기능 권한을 제한하는 보안 샌드박스가 아니다.
- PNG 전송 성공과 SNS 게시·서버 영구 저장 성공은 별개다. 호스트의 완료 콜백이 후자를 담당한다.
- 브라우저의 팝업 차단·COOP 정책·WebGPU 지원에 영향을 받는다. 실제 확인 환경과
  미검증 환경을 최종 기록에서 구분한다.
