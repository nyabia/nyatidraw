# 부드러운 선택 영역

선택은 문서 픽셀마다 0–255의 적용량을 가진다. 0은 보호, 255는 전부 적용이며
중간값은 부분 적용이다. 레이어에 저장되는 마스크와 달리 선택은 편집 중의 임시 상태다.
획을 시작할 때의 선택을 고정해, 입력 중 선택 상태가 바뀌어도 같은 획의 결과는 바뀌지 않는다.

## 조작

선택 도구 속성의 확장·축소 옆에서 경계를 부드럽게 할 수 있다. 반경은 문서 픽셀
단위이며 1–64px이다. 세 번의 분리 가능한 box filter로 Gaussian에 가까운 경계를 만든다.
선택 가장자리 바깥으로도 coverage가 이어지고, 캔버스 밖의 음수 좌표를 유지한다.
반복 적용은 경계를 더 부드럽게 만든다. 선택 조작 자체는 작품 Undo에 포함되지 않는다.

점선은 128 이상의 coverage 경계를 나타낸다. 점선 바깥의 낮은 coverage도 실제
붓질에는 적용된다. 점선의 표시와 편집 적용량을 같은 Boolean 값으로 취급하지 않는다.

## 픽셀 보존 계약

- 추가 선택은 두 coverage의 최댓값, 빼기는 0에서 제한한 차이, 반전은 `255 - coverage`다.
- 브러시·지우개는 dab마다 coverage를 반영한다. 0 영역은 원본 채널을 정확하게 보존한다.
- 채우기·보정도 coverage만큼 적용한다. 연결 영역 탐색에는 nonzero 여부를 사용한다.
- 복사는 premultiplied RGBA 네 채널에 coverage를 곱한다. 잘라내기는 그 복사량을
  원본에서 빼므로 복사 부분과 잔여 부분의 합이 원래 픽셀이다.
- 이동·변형은 원본과 선택 coverage를 함께 계산한다. 움직이지 않은 픽셀은 원본을
  유지하며, 부분 선택을 제자리에 변형했다고 불투명도가 줄어들지 않는다.
- 레이어 alpha에서 선택을 만들 때는 실제 alpha와 활성화된 레이어 마스크를 반영한다.

## 저장 및 호환성

이진 선택을 가진 기존 획은 이전 packed-bit 형식과 해시를 유지한다. 중간 coverage가
있는 획은 `NYSEL003`과 별도 schema flag를 사용한다. payload에는 signed origin,
크기, byte coverage가 포함된다. 구버전으로 열어 coverage를 조용히 잃어버리는 대신
지원하지 않는 형식을 거절한다. 파일에 기록된 획의 선택과 현재 임시 선택은 별개다.

메모리·픽셀·연산 상한을 검사하고 실패하면 원본을 유지한다. GPU도 같은 byte coverage를
사용한다. CPU/GPU 반올림 차이와 실제 검증 결과는
[확장 검증 기록](workflow-expansion-validation.md)에 기록한다.
